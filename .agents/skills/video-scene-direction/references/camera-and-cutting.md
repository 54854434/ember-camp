# 摄影与切镜调度

先从动作表选出观众必须看见的三个状态，再决定景别、机位和切换。完整肢体、空间比例、反应、细小的接触点各需要不同覆盖。

## 一镜一个主要职责

| 目的 | 机位怎么设计 | 剪切时注意 |
| --- | --- | --- |
| 交代人物和空间 | 远景或全景，保留出入口、对手或守护对象。用一条慢弧移或横移揭开关系 | 出镜时让观众知道下一镜会看哪边 |
| 让舞蹈或动作易读 | 全身构图主要负责脚和动力链。并行横移或跟拍保留脚底和头顶 | 跨镜对齐承重脚、朝向、动作阶段和鼓拍 |
| 突出接触或结果 | 用近景或插镜看到脚落地、手接物、布条被冲起等关键信号 | 接触前切入看过程，接触后切入强调反应或结果 |
| 传达情绪变化 | 先选主要视点，再用反应镜头、轻推或保留一拍表演 | 对话可让说话声留在听者镜头。舞蹈或奇幻高潮后可用后拉交代余波 |

- 一段短生成先用一条可辨认的运动。写清机位高度、起点、方向、幅度和结束构图。横移记录近处和远处地标的不同位移，环绕记录看见主体哪一侧，后拉记录什么进入画面。用户要求全程移动时，每段都指定持续运动，人物收势时机位仍然可以缓行。
- 连续镜头可随走位转弯、改变高度或景别。区分摄影机位置、镜头朝向和主体动线，在每个转折处写明经过的地标、转折原因和下一构图。人物进入同一空间的另一区域时沿用同一镜号。具体做法见[电影镜头设计](cinematic-shot-plan.md)。
- 按「起幅与初始焦点 → 动作触发 → 机位经过的位置与速度 → 落幅与可见信息」写。把摄影机位移、原地摇摄、光学变焦、焦点转换和后期裁切分别判断。横移看前后景视差，摇摄看光心两侧如何进出画面，变焦看画角与主体大小，拉焦看清晰面。仅凭一张图或证据不足的片段只给有依据的候选路径。
- 对话的正反打先建立两人连线，注明机位在哪一侧和各自的视线目标。过肩或单人镜接回同框时，同一人的视线仍落在同一对象上。需要表现共同反应或同时完成的道具动作时，保留关系清楚的双人取景。变更轴线时用可见走位、机位运动或新建立镜头重新交代。
- 切镜写清新增信息或节奏理由。动作中间切要对齐方向与阶段。接收到新信息时可切反应，跨空间同步可用交叉剪辑。需要方向变化时，用新的广景或连续运动让观众重新定位。具体技法见[拍摄与剪辑技法速查](../../short-video-production/references/camera-and-editing.md)。
- 选一种观众能认出的接点。动作接切要对上同一物件、朝向和动作阶段。视线切到人物正在看的物件或位置，选能够解释其反应的景别。形状匹配要让两镜的轮廓、尺度或运动方向确实可对照。遮挡剪接交代掠入的近景物、覆盖方向、剪切时机与下一镜如何露出。声音桥交代哪段声音先行或延续，以及画面的新信息何时出现。选中后写出切前和切后的可见状态。
- 先写首帧、切前帧和切后帧应看到什么。要精确卡拍或精确裁切时，在时间线定帧。H3 四步模式的分段、尾帧检查和机位排查见[运镜控制与分段验收](../../h3-visual-prompting/references/camera-control.md)。
- 用户定了镜数和强度时按该目标设计，明确一镜即连续拍摄。自动模式依需要揭示的信息与可用时长选择切镜数量。将「更夸张的机位」落实为起点离前景多近、高于或低于主体多少、运动经过哪个地标，画面如何改变。仅在实际入口有相关数值控制时填写对应参数。
- 远距对望用地标、物件大小与场景纵深证明距离，正反两镜保持同一地形关系。追逐先确定通道、障碍和领先方，再用跟拍展示距离确实如何改变。风格化道具碰撞的近景，接触前后保留同一对道具、方向和可辨认的接触点；全景和近景分别交代空间与接触。

## 舞蹈 MV 动态跟拍

K-pop MV 的“动感”应来自摄影机在空间中的真实路径、景别变化和有目的的切镜，而不是只靠快速变焦、抖动或后期裁切。用户要求摄影机持续运动时，每个镜头都要有可辨认的位移；即使舞者短暂停顿，摄影机仍可缓慢横移、弧移或推进，不要退回固定机位。

- **逐镜写完整路径。** 按“起幅位置与高度 → 摄影机移动方向和速度 → 触发移动的舞步 → 经过的人物哪一侧 → 落幅构图”描述。把舞者动线与摄影机动线分开写，说明摄影机是在前侧跟随、平行横移、向后退拍，还是绕人物做有限角度的弧移。
- **可选的 MV 跟拍方式。** 前侧三分之四角度向前推进并轻微横移，适合开场建立人物和舞台；侧向平行跟拍适合连续脚步和髋部律动；约四分之一圈的短弧绕拍可在身体 Wave 或转身时改变视角；舞者向镜头移动时，摄影机可低机位后退跟拍；强重拍可用短促推进或改变高度强调，但动作前后要保留足够的全身信息。不要为了“环绕感”无缘由地整圈旋转。
- **以动作可读性决定景别。** 舞步、脚跟脚尖和重心转移需要全身景，画面同时保留头顶、双脚和脚下地面；髋部隔离或身体 Wave 可短暂靠近到中全景，但不能连续裁掉脚部，使观众看不懂支撑关系。竖屏画面尤其要预留人物移动和手臂外展空间。
- **控制透视和稳定性。** 低机位可以增强舞台气势，但避免过近的超广角把腿、臀或头部夸张变形。稳定器跟拍应有速度变化和自然惯性，不应出现无因抖动、漂移、穿过人物或不可能的瞬间换位。
- **切镜跟随音乐，也跟随动作阶段。** 可在鼓点重音、动作定形、转身完成或新的舞步短句开始时硬切。切前、切后要对齐人物朝向、承重脚、髋部动作方向、手臂阶段和音乐位置；切镜必须带来新的角度、景别或表演信息，不能只重复同一画面。
- **短视频镜数按信息量决定。** 约 15 秒的舞蹈片可用少量有差异的机位组织节奏，例如前侧推进、侧向跟拍、低机位后退；这只是设计参考，不是固定镜数。若同一镜头能清楚展示动作，就保留连续跟拍；若切镜会破坏脚步或重心的阅读，优先不切。
- **审片时检查真实运动。** 比较背景地标和人物在画面中的相对位移，确认是摄影机真的移动，而非人物移动或数码变焦造成的错觉。逐镜检查头顶、双脚、手臂是否出框，并核对切点两侧的动作阶段。

舞蹈动作本身的承重、髋部隔离与音乐短句，见[舞蹈与冰上动作设计](dance-and-skating.md#twerk-与高能-k-pop-舞蹈)；配乐卡拍见[高能舞蹈配乐与动作卡拍](music-and-sound.md#高能舞蹈配乐与动作卡拍)。

## 由镜头任务决定视场和清晰面

先定空间位置和画框，再选视场、焦点与背景可读程度。机位改变取景透视和遮挡关系，焦距与取景格式决定视场。景深还与拍摄距离、光圈等有关。CINEDANCE 的角度和距离按它示例的画面理解，使用数值控制时分别核对画幅、测量方向、实际相机位置和模型入口。 [Nikon 对视场与拍摄距离的说明](https://www.nikonusa.com/fileuploads/pdfs/Nikkor%20lens%20Broch_061017.pdf)

| 镜头任务 | 写给模型的可见目标 |
| --- | --- |
| 常规空间关系 | 两人保持可判断的距离，桌边与门框留在画中，人物身体比例自然，能同时认出手中物和视线对象 |
| 广角交代环境或贴近动作 | 保留近处边缘与后方地标，在移动时让二者明显产生不同位移。脸部重要时核对脸离机位和画边的位置 |
| 极宽空间或贴地揭晓 | 从贴近的具体前景启程，露出大范围环境，说明需要保持直线的墙、柱或地平线，按读图任务决定背景是否清楚 |
| 人像表演 | 用旁边人的肩线或背景点证明空间，焦点优先给眼神、口型或一只关键手，留出反应需要的画面和时间 |
| 远距观察 | 交代机位与人物相隔的空间，例如一段走廊或对街。后景尺度显得贴近时，仍保留能证明人物实位的地标 |
| 远处遮挡后的揭晓 | 从远处隔一件近处遮挡物取景，明确遮挡何时移开或焦点何时转到人物，末幅可辨识所需信息 |

同镜需要稳定光位时，写光源、摄影机与人物的相对侧，指定随着走位可见的轮廓或明暗变化。比如门外日光从人物身后进入，摄影机留在室内，推近时先保住门边轮廓，人物转向桌灯后才看到眼睛。主体或机位转向时以场景地标确认光仍从原处来。镜头出现焦段或光线漂移时，回看首帧、转折帧与落幅的边界、脸和背景尺度、焦点、阴影与高光方向。

## 硬切与过渡怎么选

先定每个真实切点的目的、前镜落幅和后镜起幅，再选剪法。硬切直接换画面，动作、视线、构图和声场也可以在硬切处匹配。有过渡需求时选择能解释该变化的手法。

| 画面需要 | 剪法与模型正文 |
| --- | --- |
| 突然发现、反应、冲击或新信息要立即进画 | 硬切。写明切换触发、前镜最后看见的事和后镜开头立刻看到的主体。同一时空继承站位、方向和道具状态 |
| 从另一角度继续同一动作，或保持对话视线 | 用动作接切或视线匹配，可直接硬切。指出前镜切到动作的哪一阶段，后镜从同一事件或紧接的阶段开始。正反打保留对象与视线方向 |
| 希望换机位更隐蔽、强调相似关系或先听到下一场 | 挑一项具体接点。遮挡转场写遮挡物如何入画、何时覆盖、后镜怎样露出。形状匹配写哪两个轮廓、画中位置和运动方向相接。声桥写声音在画面切换前先入或在切换后延续 |
| 需要让观众察觉时间流逝、回忆或段落结束 | 按意图选择叠化、淡入淡出，或硬切到有明确新状态的画面。说清前后场景和变化证据。必须精确对帧或叠化持续时长时留给剪辑时间线 |

单镜里镜头经过遮挡、继续沿原路径揭示人物时，按一镜内的运镜写。H3 同一生成段的真实切镜按[官方正文审查](../../h3-visual-prompting/references/h3-formats.md#交付前审查官方正文)写一个切点。分批独立生成时，按下节设计段间接点。

## 让独立生成的片段能接起来

同一场戏因生成时长拆段时，先为每对相邻段确定观众从哪里接住动作、空间或信息。再选切镜或连续画面，并把前段最后可见状态与后段第一个可见状态分别写进实际生成正文。

| 要的效果 | 接点怎么做 | 要核对什么 |
| --- | --- | --- |
| 观众感到是一场戏，可以换机位 | 因动作、视线、反应或新声音进入同侧近景、道具插入或明显不同的景别。可直接硬切。 | 地标、行进方向、视线、身体朝向、手与道具接触阶段都对上。镜头裁掉的信息在后续再次入画时继续保持。 |
| 观众感到同一台摄影机从未停拍 | 选上段清楚的实际结束帧或可保留的末段帧，下一段从该画面继续，按[H3 跨段首帧输入](../../h3-visual-prompting/references/h3-formats.md#跨生成段的实际帧输入)接入。 | 构图、人物姿势、受光、物件状态和正在发生的动作相合。首帧只固定起点，快速运动还要写速度、方向和重心；适用时用实拍连续引导验证。 |
| 需要同时落在准确的起点和终点 | 当两张干净画面都已确定时，使用支持首尾帧的入口，写清中间可行的动作和机位路线。 | 两帧画幅一致，主体、地标与光源能通过已描述的运动自然对应。 |

- 每个有状态继承的接点内部记一行「前段落幅｜切点触发或输入帧｜后段起幅｜声轨接法」。动作在切点跨镜时，保留动作正在进行的阶段和方向，例如前镜手已离桌，后镜开场手仍在空中继续够向目标。允许留短剪接余量，但成片只保留一次起手、一次接触和一次结果。对白或静默反应用闭唇、眼神稳定、呼吸等可辨认时刻作接点。切法需要的变化可在实际可见的画面里确认。
- 同空间先统一画幅、帧率、主要光源和背景声，再核对上一段实拍尾部与下一段实拍头部。声音桥由一条连续底声或一次提前/延后的具体声响承担，影响剧情的对白、撞击、锁扣等按最终画面校准。字幕、界面等后期叠层可跨段持续。
- 有样片时先直拼试看并试听，再按可见动作逐帧微调。相邻段共用的接点帧若形成重复，剪去一份。错接先判断是需要调整剪切帧、姿势或物件状态错了、机位差异太小，还是音色与环境声突变。优先保住通过的片段，只修失配接点。

## 从参考推导路径与修正样片

- 确认是在设计新镜头、借鉴拍法还是定位偏差。静帧用于判断可见构图、人物朝向、前中后景和可通行空间。首尾两张图先对照主体、地标与物件状态，再规划中间的动作、机位和必要的焦点变化。只在画面之外的空间会改变动作或切点时，核对对应视角或说明布局假设。
- 研究视频时按关键帧比较画面边缘、近远地标的相对移动、主体大小与清晰面，并核对实际听到的对白和音效。相机位移、主体移动、变焦、移焦和后期裁切可以产生相似结果。资料不全时说明观察依据和可能的解释。
- 用拍摄单记录镜号、镜头任务、起幅机位与构图、人物起始状态、焦段或画角和景深、相机路径与速度、触发点、焦点、落幅和转场。焦点静止时注明目标即可。供多镜交接时分别给每段独立正文，用户要提示词时把这些信息写进模型实际读取的描述。
- 样片偏差定位到首次发生的时间或帧，写出预期、实际画面与修订后要观察的证据。优先只改一处对应的摄影指令。修复关键机位时给能完整替换的对应镜头正文，同一空间的切前切后仍按[切点站位](performance-and-blocking.md#在切点对齐人物站位)复核。
