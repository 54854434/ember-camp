# 运镜控制与分段验收

用于四步 Turbo 实际出片后，处理机位几乎不动、运镜动错方向、主体转身代替摄影机运动、裁切乱跳和切点跑偏。先保留原提示词、生成参数和可用画面。只有成片或帧可看时才报告具体效果。以下是排查与导演方法，出片表现按各镜头实际验证。

## 先把运镜写成看得见的变化

- 一个短片段先安排一条主要机位路径。首句给出**起始机位、主体朝向和起始构图**，第二句写**机位怎么走、相对哪个物体向哪一侧动、幅度和速度**，再写**结束时的机位和可见构图**。全程移动时，用「从开场第一拍持续横移，末尾仍保持缓慢移动」写出运动的起止。景别变化由该镜的路径和用途决定。
- 用前后两个处于不同深度的地标检验机位。例如横移时观察近处石板接缝是否比远处树篱在画面上移动得快。环绕时观察画中人物与背景的相对角度，人物需要维持朝向时写明。推拉时写出镜头距离怎样变、什么近处边缘逐渐露出或退出画面。地标应从开头就可辨认。
- 把画面方向、机位方向、人物朝向分开写清。需要精确控制时先锁定容易判断的起始和结束位置。比起只加「电影感、动态镜头、顺滑运镜」，先写摄影机与布景、人物之间的关系。术语可参考[拍摄与剪辑技法速查](../../short-video-production/references/camera-and-editing.md)。 [MiniMax 基础模式指南](https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/docs/VIDEO_PROMPT_WRITING_GUIDE_base_en.md)
- 用户指定复杂一镜到底时，用[电影镜头设计](../../video-scene-direction/references/cinematic-shot-plan.md)把连续轨迹按动作节拍写清楚。短片段的一条主要路径是试拍起点。一条可走通的路径允许自然转向或升降。对长度和动作负荷做检查后，可先单测最易失效的那一拍，再验证完整长镜。

可替换模板，直接放进本段的 `detailed_description`。

```text
[Shot 1] 开场机位在{人物或物体}的{方位、高度}，画面是{景别与主体在画面的位置}。从第一拍起，摄影机沿{实际路径和参照物}向{方向}持续{速度}地移动，镜头始终对准{跟随目标}。过程中，{近处地标}相对{远处地标}在画面里{可观察的变化}。主体完成{主要动作}，保持{指定朝向或与相邻镜头对接的状态}。末尾机位到达{新的相对位置}，呈现{可辨认的构图变化}。
```

## 按失败现象选下一次试法

| 出片现象 | 最小修改与验收 |
| --- | --- |
| 机位几乎不动，只有人物或背景小物在动 | 将机位动作提到镜头第一句，指定起点、终点和一个清晰的视差参照。先试一条持续、较容易辨认的横移或推拉。对照首、中、末帧看地标相对位置 |
| 人物转了，背景没按预期改变 | 写清人物胸口或视线朝向哪个固定物，再给出机位从哪一侧走到哪一侧。核对人物朝向与前后景的角度变化 |
| 只是画面放大，缺少实际推进感 | 在画面边缘放一个近处参照，描述它随摄影机靠近退出画面的过程。核对前后景相对透视以及主体尺寸 |
| 镜头移动但脸、脚或道具被切掉 | 让机位保持所需的跟随距离和高度，写清需要完整保留的身体与道具范围。运动和幅度先保留一个变量，首、中、末帧逐帧核对 |
| 多个镜头被揉成一镜，或切点迟到 | 给每个目标机位单独生成一条片段，后期在精确帧硬切。各段的前后动作、视线、人物左右、光线和地标对齐 |
| 简化过的运镜仍无稳定方向 | 试自制或获授权的短运镜参考视频，用 `<Video 1>` 明确仅借机位路径、幅度或速度，人物身份继续由图片与主体定义承担。明确开场、中间、末尾构图时可试支持首尾帧或 `MiniMaxH3AddGuide` 的原生工作流，依实际接线设置锚点 |

运镜视频是实际输入，提示词标签、槽位与绑定素材必须一致。若只借视觉运动，用无声样片或依节点明确保持视频音轨未接入，再核对本机的音频槽位配对。原生 R2V 官方文档也说明 Turbo 对参考和音频的约束较弱。重要镜头用同一组参考、种子、画幅、时长、步数和 LoRA 对照提示词后，再单独换工作流或参考方式。 [MiniMax 全参考指南](https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/docs/VIDEO_PROMPT_WRITING_GUIDE_ref_en.md) · [ComfyUI 原生 R2V 与 H3 导引](https://docs.comfy.org/tutorials/video/minimax/minimax-h3-native)

## 1160 分段与精确切镜

在目前本机 1160 的素材管理器中，每段视频时长由界面参数设置，最短 4 秒。一个 `[SHOT_START]` 块对应独立生成的一段，块内 `[Shot N]` 是给模型的内部分镜提示。模型切点需要按成片实测，精确卡拍可由后期时间线确定。每个独立段内的镜头编号从 `[Shot 1]` 开始。每段时长不同就分别排队。同次用多个块时，设置正确的分段数和共同生成时长。后期按实际导出帧率检查首尾和裁切帧数。

例如 **10 秒三段舞蹈**，把原先一段里并列的弧移、横移、后拉拆开。分别提交 **4、5、4 秒** 三次，在时间线选出合计 10 秒的可用片段。1160 的「每段视频时长」对同一次提交里的所有分段生效。剪到成片约第 3 秒、第 7.2 秒时，优先对齐角色同一只脚的承重状态和屈膝阶段。固定一条节拍音轨，统一在时间线上选切点。24 fps 的切点落在整数帧上，7.2 秒可就近落在第 173 帧（按第 0 帧起算，约 7.208 秒）。

| 段 | 单独交给 H3 的运镜与主要动作 | 与邻接段对齐的证据 |
| --- | --- | --- |
| 入拍 | 机位从正前缓慢弧移到左前方，女人侧转并下沉 | 收在双脚踩实、双膝下沉的状态 |
| 主段 | 摄影机沿石板边缘横移，女人从慢拍进入连续快拍 | 从同一屈膝状态起，靠下一次重拍衔接 |
| 收束 | 摄影机缓慢后拉，女人打完最后重拍并转回镜头 | 开头脚位与上一段最后一拍一致，末尾保留人物与泳池 |

首轮优先试最容易判断的横移段，可用下列正文替换该段的 `detailed_description`。角色素材仍按用户实际槽位绑定。

```text
[Shot 1] 竖屏全身，摄影机起始在女人的左前方，镜头约在腰部高度。女人面向斜前方，双脚踩在同一块石板上，双膝已微屈。开场第一拍，摄影机沿池边的石板接缝向右平稳横移，保持女人的头和双脚都在画内。近处石板接缝向画面左侧滑过，远处树篱向同侧缓慢移动，女人仍朝着原来的斜前方。女人随鼓点完成两次慢拍回弹，随后接连续小幅快拍。末尾摄影机仍在向右移动，池沿与女人的相对位置已明显偏移，女人回到双膝微屈的接拍姿态。
```
