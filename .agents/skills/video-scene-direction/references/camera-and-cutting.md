# 摄影与切镜调度

先从动作表选出观众必须看见的三个状态，再决定景别、机位和切换。完整肢体、空间比例、反应、细小的接触点各需要不同覆盖。

## 一镜一个主要职责

| 目的 | 机位怎么设计 | 剪切时注意 |
| --- | --- | --- |
| 交代人物和空间 | 远景或全景，保留出入口、对手或守护对象。用一条慢弧移或横移揭开关系 | 出镜时让观众知道下一镜会看哪边 |
| 让舞蹈或动作易读 | 全身构图主要负责脚和动力链。并行横移或跟拍保留脚底和头顶 | 跨镜对齐承重脚、朝向、动作阶段和鼓拍 |
| 突出接触或结果 | 用近景或插镜看到脚落地、手接物、布条被冲起等关键信号 | 接触前切入看过程，接触后切入强调反应或结果 |
| 传达情绪变化 | 先选主要视点，再用反应镜头、轻推或保留一拍表演 | 对话可让说话声留在听者镜头。舞蹈或奇幻高潮后可用后拉交代余波 |

- 一段短生成先用一条可辨认的运动。写清机位高度、起点、方向、幅度和结束构图。横移记录近处和远处地标的不同位移，环绕记录看见主体哪一侧，后拉记录什么进入画面。用户要求全程移动时，每段都指定持续运动，人物收势时机位仍然可以缓行。
- 连续镜头可随走位转弯、改变高度或景别。区分摄影机位置、镜头朝向和主体动线，在每个转折处写明经过的地标、转折原因和下一构图。人物进入同一空间的另一区域时沿用同一镜号。具体做法见[电影镜头设计](cinematic-shot-plan.md)。
- 按「起幅与初始焦点 → 动作触发 → 机位经过的位置与速度 → 落幅与可见信息」写。把摄影机位移、原地摇摄、光学变焦、焦点转换和后期裁切分别判断。横移看前后景视差，摇摄看光心两侧如何进出画面，变焦看画角与主体大小，拉焦看清晰面。仅凭一张图或证据不足的片段只给有依据的候选路径。
- 对话的正反打先建立两人连线，注明机位在哪一侧和各自的视线目标。过肩或单人镜接回同框时，同一人的视线仍落在同一对象上。需要表现共同反应或同时完成的道具动作时，保留关系清楚的双人取景。变更轴线时用可见走位、机位运动或新建立镜头重新交代。
- 切镜写清新增信息或节奏理由。动作中间切要对齐方向与阶段。接收到新信息时可切反应，跨空间同步可用交叉剪辑。需要方向变化时，用新的广景或连续运动让观众重新定位。具体技法见[拍摄与剪辑技法速查](../../short-video-production/references/camera-and-editing.md)。
- 选一种观众能认出的接点。动作接切要对上同一物件、朝向和动作阶段。视线切到人物正在看的物件或位置，选能够解释其反应的景别。形状匹配要让两镜的轮廓、尺度或运动方向确实可对照。遮挡剪接交代掠入的近景物、覆盖方向、剪切时机与下一镜如何露出。声音桥交代哪段声音先行或延续，以及画面的新信息何时出现。选中后写出切前和切后的可见状态。
- 先写首帧、切前帧和切后帧应看到什么。要精确卡拍或精确裁切时，在时间线定帧。H3 四步模式的分段、尾帧检查和机位排查见[运镜控制与分段验收](../../h3-visual-prompting/references/camera-control.md)。

## 从参考推导路径与修正样片

- 确认是在设计新镜头、借鉴拍法还是定位偏差。静帧用于判断可见构图、人物朝向、前中后景和可通行空间。首尾两张图先对照主体、地标与物件状态，再规划中间的动作、机位和必要的焦点变化。只在画面之外的空间会改变动作或切点时，核对对应视角或说明布局假设。
- 研究视频时按关键帧比较画面边缘、近远地标的相对移动、主体大小与清晰面，并核对实际听到的对白和音效。相机位移、主体移动、变焦、移焦和后期裁切可以产生相似结果。资料不全时说明观察依据和可能的解释。
- 用拍摄单记录镜号、镜头任务、起幅机位与构图、人物起始状态、焦段或画角和景深、相机路径与速度、触发点、焦点、落幅和转场。焦点静止时注明目标即可。供多镜交接时分别给每段独立正文，用户要提示词时把这些信息写进模型实际读取的描述。
- 样片偏差定位到首次发生的时间或帧，写出预期、实际画面与修订后要观察的证据。优先只改一处对应的摄影指令。修复关键机位时给能完整替换的对应镜头正文，同一空间的切前切后仍按[切点站位](performance-and-blocking.md#在切点对齐人物站位)复核。
