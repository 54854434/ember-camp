# 样片拆解与风格迁移

从一条样片挑一个 3–6 秒段落，先确定想学哪项。可单选构图与光色、动作与表演、机位与剪辑或声音层。实际能观看时记录时间码和关键帧。如果只看到了官方提示词和案例说明，记录为「设计意图」，把镜头执行和效果留待实测。

## 拆解结构化提示词与分镜样稿

用户给完整提示词、技能、截图或分镜表时，从全局设定、镜头正文和收尾分别找出可复用的设计决定。对每项提炼「用在什么场面 → 实际发生什么 → 从哪个景别、动作或声音看得出 → 失败时最先删减或补强什么」。同时阅读已经有的规则，补足缺失的适用条件或正文写法。重复原则可链接到现有位置。

- **高密度动作样稿。** 分析开场抓手、哪一拍转为反攻、高潮如何放大空间、最后一拍何时结束。再从一段里拆出处于不同位置的光效来源、随身拖尾、命中留下的痕迹、远处后续反应，以及用于接剪的相同轨迹或遮挡。写 H3 时围绕一个主事件按先后组织这些层次。将固定镜头时长、精确抽帧和全屏闪变视为具体样稿的实现选项。
- **剧情与漫剧样稿。** 从场次目标和人物关系找信息何时转手。把相机路线与人物路线分开推演，写清一次视线、持物或落脚变化如何跨镜继承。需要表演时从当前景别挑出能读懂的反应。服装或时间有剧情变化时，记录变化以前和以后的版本及生效镜头。
- **素材与对白样稿。** 角色总览图先提取识别点、相互匹配的视角和服装版本。按片段挑实际需要的图与视角。对白按说话人、语气、动作与听者反应安排，现有录音优先于语速估算。锁定的原文须能从分段还原。

学到的新做法按对应任务更新执行资料与调用入口。技能只保留可迁移的手法、适用条件和如何验证。样稿全文、一次性人物道具和测试情节留在各自项目中。区分从文字推断的设计、实际看到的成片和本机复验结果。

用户要求查找同题材拍法时，从该镜的问题出发。优先看指定样片、可实际查看的发行片段、分镜或制作人员一手解析，挑一两种针对同一问题的处理。留作品名、片段时间或可定位证据、采用的技法和落到的新镜号。海报只能支持静态视觉判断，文本模板可支持技法选择，实际移动、节奏和声音按能看到听到的素材判断。查找受限时仍可依据现有参考完成设计，注明证据范围。

## 观察一段镜头

| 观察维度 | 记录的证据 | 写进 H3 的位置 |
| --- | --- | --- |
| 空间与构图 | 主体在画面哪一侧、身体截到哪里、前景遮挡、至少两个近远地标 | 在 `detailed_description` 开头写空间关系和基准构图，镜头内写构图如何改变 |
| 光影与色彩 | 主光来自哪一侧、有多软、人物与背景怎么分开、主色和点缀色落在哪里 | 风格开场写贯穿全片的光色，镜头内写灯、极光或反射的变化由什么触发 |
| 材质与介质 | 布料是垂落还是挺括，积水反射谁的光，烟雾或粒子出现在哪一层 | 写可看见的材质特征，再写最关键的一次次级运动 |
| 表演与摄影 | 起势、动作峰值和收势，机位轨迹、速度、焦点或视差怎样配合 | 镜头正文按时间顺序写动作。优先保留一个表演变化、一条能验证的机位路径 |
| 剪接与声音 | 切前后是否共用脚位、动作方向或遮挡物，声音在哪一帧开始或延续 | 切点进入分镜时间表。近处动作声写进本镜，环境底声与统一音乐单列 |

## 从官方案例学什么

- **Seedance 2.0 复古舞蹈。** 官方案例提示把动态跟拍与足部插镜交替使用，并用流苏的摆动突出动作。迁移到 H3 时，先单独做全身侧跟，再按同一拍位与同一只脚的落地状态补插镜。流苏在转身或踢步时按惯性摆动。 [字节跳动 Seedance 2.0 官方示例](https://seed.bytedance.com/en/blog/official-launch-of-seedance-2-0)
- **Seedance 2.5 戏曲舞台。** 官方案例将水袖的弧线、绕行机位和旗面掠过镜头的遮挡结合起来。迁移到 H3 时，可先做一个绕行镜头，让袖端从抬起、划弧到落下都在画内。若要换主体，可分别拍摄遮挡前后两段，并在遮挡最完整的帧上接剪。 [字节跳动 Seedance 2.5 官方示例](https://seed.bytedance.com/en/blog/one-take-creation-flexible-referencing-introducing-seedance-2-5)
- **Seedance 2.5 白模预演。** 官方示例把动线和机位交给粗模，把人物、布景与光照交给其他参考。H3 可借这个分工做简易预演。没有验证运动参考兼容性时，先从预演抽取起始构图、主体动线与终点，按实际支持的工作流使用文字、身份图或关键帧。 [火山方舟 Seedance 2.5 提示词指南](https://console.volcengine.com/ark/region%3Acn-beijing/docs/seedance-2-5-prompt-guide)

## 按题材挑可见特征

下面是写法起点，实际参数从当前片子的参考与情绪出发。每段先选两到三个决定画面观感的要素。

| 视频风格 | 可迁移的画面特征 | 本段值得拍清楚的动作 |
| --- | --- | --- |
| 真人短剧 | 窗侧软光、压低背景亮度、眼睛和面部保留细微反光 | 目光先移，短停一拍，再让说话声延续到对方反应 |
| 舞台舞蹈 | 暖面光与窄轮廓光、全身构图、用地板边线显示侧移 | 清楚交代重心和落脚，再让发尾、流苏随转身回摆 |
| 二维动漫 | 清晰剪影、有限色阶、形状干净的阴影与前后景分层 | 用明确的预备姿势、快速移动与短停顿形成节奏 |
| 国风或奇幻 | 前景暗剪影、中景受光主体、远处空气层次与比例参照物 | 先显现光源变化，再让近处浮尘与远处水面依次响应 |
| 写实纪录片 | 自然主光、真实场地色温、具有深度参照物的环境 | 保留事件发生前后片刻，摄影跟着事件移动 |
| 产品或物件叙事 | 轮廓、材质表面和高光路径，背景亮度服从物件辨识 | 拍清一次接触或结构变化，并让焦点落到得到的新信息 |

## 输出和验证

1. 写成三条可检验的要求。例如侧后方暖光勾出发尾、地面线条从近处快速划过、右脚踩实后衣摆才短暂扬起，分别对应光线、机位和动作。
2. 记录参考的实际职责。用图提供主体外观、色彩或构图。使用视频提供动作或机位时，先确认 H3 工作流实际接入何种参考，保持提示词与其对应。详细写法见[提示词增强与模型转换](prompt-enhancement.md)。
3. 对比原版和增强版，用同一素材和采样设置先改一项。对照首帧、动作峰值和尾帧，逐项看色光与身份是否稳定、机位是否真实移动、触发和反馈是否可辨。可先测单镜，再检查成片接点。输出尚未渲染时，标记为待验证。

评估长期改版时可用不同类型的固定任务，例如等待、双人互动、近距与远距奇幻场面、角色展示和多人调度。保持需求和设置一致，条件允许时随机顺序匿名比较并独立复测。文字审查与视频评审各自记可定位依据，围绕[美术六项检查](look-design.md#用画面判断美术安排)记录具体进退。
