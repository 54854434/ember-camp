# Seedance 方法与提示词转换

参考火山方舟 Seedance 2.0、2.5 提示词指南和字节跳动公开的提示词优化资料。把可复用的拆解方法用于不同模型。操作入口、能力和素材兼容性依目标版本确认。

## 一句话创意的自动增强

用户给一句话、一段想法、一个画面或一个主题，或明确让模型自由发挥时，默认把它扩成一份完整的导演提示词。技能主动补写能形成成片的空间、角色行动、关键画面变化、镜头与声音，细节量按构思出来的场面决定。用户的主体、情绪、世界观和明确要求是创作依据。参考图只按实际用途继承。用户要求原样保留、只排版或只修一项时，按指定范围处理。

1. **先找可拍的看点。** 从用户已经给出的人物、物件和地点选一个能产生变化的关系。有多种成立的方向时，对照拍动作过程和拍某个观察视点所带来的区别，再选其中一个。新创意至少确定一个属于这个场景的可见变化。剧情可来自人物的选择，写真可来自一次光线或目光变化，规模感可来自运动之后才看见的空间。把主要看点放在短片能够完整兑现的位置。
2. **先想成片，再倒推提示词。** 先想观众最后应该记住的画面、声音或结果，倒推开场需要看见什么、哪一步让变化发生、摄影机要在哪一刻揭示它。按实际播放顺序写回正文。可用同一个事件同时推动镜头、材质变化和声音，使新增细节指向同一个看点。常规动作自然带过，在揭晓、接触和结果等决定效果的节点才展开。
3. **让画面完整，控制关键变化。** 确定开场构图、角色主线、需要维持的场景关系、环境反馈和收尾构图。给每个关键变化指定一个主导层，由主体行动、表演、摄影揭示或声音接替推动。辅层与同一事件配合，写清地标、实际可见的变化与结果。现有参考已经明确展示某项细节时，以清晰的素材职责和入画时机承接，补足用户要改变的部分与该镜仍需说明的动作。次要细节按需要放开或省略。
4. **交接成稿。** 按[成稿倒查](../../short-video-supervisor/references/review-loop.md#从成稿倒查镜头)检查关键信息写到了实际生效的镜头。交付形式和本机默认时长见 [1160 规则](../../h3-visual-prompting/references/h3-formats.md#适配本机-1160)。用户未定画幅时按场面决定，简短注明。

这里借鉴 Seedance 2.5 的关键动作取舍、WanPE 从视频反推描述的研究，以及 H3 将创作意图转成原生结构的方式。这是本地提示词策略。交付前核对用户原意、时空连贯和新增画面价值，确认新增细节能在具体画面中看见或听见。提示词长度由任务决定。 [火山方舟 Seedance 2.5 指南](https://console.volcengine.com/ark/region:cn-beijing/docs/seedance-2-5-prompt-guide) · [WanPE 跨模型实验](https://arxiv.org/html/2609.30221) · [MiniMax H3 Context-IR 说明](https://huggingface.co/MiniMaxAI/MiniMax-H3) · [PEBench 的导演创意与保真评估](https://arxiv.org/html/2610.11736)

### 依可控程度安排细节

| 意图 | 展开多少、交给哪一层 |
| --- | --- |
| 一句创意或希望自动发挥 | 先补具体拍法和一个可辨的结果，再增能丰富画面且同向的光影、环境运动、材质或声音。用连贯动作句保住主要感受，次要花色、点缀与小反应可留给模型 |
| 有明确表演、机位、招牌、穿搭或事件顺序 | 先锁用户明示的原文、顺序和构图。把「要看清」「只说这一句」等要求落到可见时段、触发、画框和后续状态。确实同时发生的画面和声响放到同一拍 |
| 有清晰的参考或现成预演 | 先把素材与身份、场景、动作、机位、声轨逐份对应。只增强实际缺失的维度，减少和强参考重复或冲突的指令。按目标模型核对引用和真实支持的输入能力 |
| 用户指出实际偏差 | 限定到发生问题的镜头、声轨或素材职责，先改最可能影响目标的一处。多项一起改后可记录组合有效；要判断是哪一项起作用，再固定其余条件逐项对照 |

逼近参考观感时，先明确要接近的是构图与光色、动作与运镜、情绪变化，还是整段节奏。选一两个最影响观感的差距来改，并保留原故事和已经通过的部分。需要比较最终效果时用[同条件样片方法](../../short-video-supervisor/references/review-loop.md#比较一句话增强的收益)。

## 明确分镜或精确控制时的流程

1. **先锁意图。** 写清主体、目标、叙事回报或动作结果、时长、画幅、必须保留的视觉与声音。局部修改只增强受影响的一项。完整镜头设计按场面决定动作、机位、剪辑和声音如何配合。
2. **分配素材职责。** 身份图供人物外观，场景图供空间，运动片段供动作或运镜，音频供旋律、节拍、音色或环境。每份素材注明要继承的东西及生效位置。动作用的参考与运镜参考冲突时，为这个镜头选一个主要目标并重排素材。
3. **先排画面时间。** 每镜确定起始构图、主体动作、次要变化、结束状态、出入镜接点和声音。新写或重写完整 H3 视频段时，统一按[逐秒检查画面进程](#逐秒检查画面进程)覆盖从开场到收尾。局部修改从问题前一拍查到受影响的后续状态。需要精确同步时另标关键接触帧和切点。
4. **按目标工具输出。** 成稿前查缺失指代、同一素材多义、起终点矛盾、动作拥挤、音效无触发、切镜是否新增信息。删掉无法改变执行的重复风格描述和泛化词，保留可见、可听、可检查的动作细节。
5. **审片后只改可定位的问题。** 记录失败时间码和观察。先在同一素材、采样设置与种子下改一个因素，例如把「跳得有力」改成指定承重脚和落拍。基线与改写各自核对动作、真实机位变化、剪接和同步。

### 根据场面复杂度增加细节

一句话也可能要求多段叙事、多人协作、大范围变化或多层场景互动。按画面要交代的信息决定展开程度。单个复杂长镜可以按空间节点写足过程，多镜按各自的叙事任务分配细节。想要类似即梦的自动导演效果时，题材明确而拍法未定的部分可由技能完成设计。

1. **先梳理场面。** 组织主体识别和素材职责、固定地标、人物路线、主光与色调、会改变的道具及环境状态。列出用户明确要求的事件，确定不同人物的行动在哪一拍交汇。把时间优先留给揭示、接触、结果和需要看清的状态变化。
2. **逐镜把同时发生的事写顺。** 按「入镜状态 → 主动作和触发 → 摄影机怎样跟随或揭示 → 环境响应与听觉 → 出镜状态」写自然叙述。前、中、后景都参与时，指定各自在画面哪一层、由同一事件依次触发还是独立运动，写清关联的空间、方向和结果。用焦点、遮挡和画框引导注意力，并给关键动作留可见空间。需要交代复杂场面时，保留这些细节。
3. **动作链和状态跨镜继承。** 在新机位重新定位必要地标、角色和可见道具。上一镜的持有关系、运动方向、破坏和残留效果按剧本进入下一镜。若在一个生成段内难以拍清所有关键状态，按本机入口和时长决定是重排动作、调整构图或拆段，并在同一可见事件上接剪。
4. **翻译为目标格式。** 全局设定与逐镜安排是导演稿的组织方式。模型正文仍按 H3 对应字段写，把影响生成的内容放进实际镜头。剪切才新增镜号。每段独立生成时让该段所需的地标、素材职责和起止状态能独立成立。具体画面与声场组织见[电影镜头设计](cinematic-shot-plan.md)。

Seedance 2.5 公共指南按素材指代、概述和逐段情节组织复杂提示。H3 全参考指南也按每镜的信息负荷分配描述。实际措辞和细节密度以目标入口的成片为准。 [Seedance 2.5 写作与时间轴指南](https://console.volcengine.com/ark/region:cn-beijing/docs/seedance-2-5-prompt-guide) · [MiniMax H3 全参考指南](https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/docs/VIDEO_PROMPT_WRITING_GUIDE_ref_en.md)

### 逐秒检查画面进程

**先导演，再增强，最后适配语言。** 先想清观众如何看懂这一段，再按约一秒的窗口内排，从首帧覆盖到片尾，不足一秒的尾段也有明确落幅。每个窗口至少说清观众在看什么、这一拍有什么变化或延续、下一拍如何接上。同时核对动作位置、画框和听觉重点。最后用目标模型适合的自然语言重写，把影响画面的内容写进实际镜头正文。英文成稿校对时保留动作先后、方向、持续时间、原台词与原字。

同一个动作跨几秒时，用开始、持续、转折和结果串起来。连续跟拍、凝视或静止本身可以占多拍，须在导演稿和正文明确它有意维持的状态，并交代持续到哪个可见事件。所有关键秒拍必须能从英文或中文成稿还原；连续状态可在一句话中覆盖多拍。把细节优先给接触、表情转折、关键揭晓和结果，避免为凑每秒一件事添加碎动作。

| 层次 | 排期时确认什么 |
| --- | --- |
| 画面重点 | 观众此刻看清谁、哪个部位或什么变化。接触、受力、反应、停止的顺序必须可读 |
| 机位或剪接 | 摄影机在何处跟随、加减速或停止，最终露出什么。发生剪切时记下精确切点、接续的动作状态或声音 |
| 环境与声音 | 哪些变化来自同一触发，哪些是持续的背景。动作声落在可见触发处，后续反应按传播路径出现 |
| 持续状态 | 素材和地标是否继续有效。持物、损伤、朝向、光源及仍在发生的运动怎样跨秒、跨镜接下去 |

先为关键接触和结果留可读时间，再排同拍的次级运动。台词、表演或运镜能同时发生时按实际重叠计算。声音可自然跨越一秒边界或切点。发现某一秒堆了几个互相抢注意力的动作时，先重排主次或把结果留给下一拍。时间窗口用于检查覆盖，镜头时长由动作和剪接目的决定。

- **H3 1160 正文。** 把各秒计划合并为自然连续的动作阶段。用接触前的等待、动作触发和必要的近似持续时长表达先后、同步和延迟。真实切镜才用 `[Shot N] At MM:SS.mmm`。逐秒表保留在内部，用户明确要时间表时再给。需精准对帧时以实际参考或剪辑校准，提示词中的时间用于引导节奏，执行偏差用样片确认。
- **Seedance。** 参考火山方舟指南，2.5 可使用连续的整数秒时段，优先给剧情变化分配合理长度。2.0 优先用镜号安排。需要频率、毫秒级或逐帧对齐时，根据入口用真实参考或后期时间线控制。

一秒的规划粒度是本地制作方法。Seedance 2.5 指南建议时间轴连续并控制每段信息量，MiniMax 把格式化时间点放在实际切镜，Sora 指南提供了用动作阶段和可数的动作安排节奏的做法。 [火山方舟 Seedance 2.5 时间戳指南](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh) · [MiniMax H3 镜头与声音指南](https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/docs/VIDEO_PROMPT_WRITING_GUIDE_base_en.md) · [Sora 2 动作与时序指南](https://developers.openai.com/cookbook/examples/sora/sora2_prompting_guide#control-motion-and-timing)

### 把导演词改成模型可执行的内容

逐秒导演稿允许使用情绪、节奏和摄影术语。增强时先逐项找它对应的可见或可听证据，再重写成英文或用户指定的正文语言。

| 导演词的用途 | 在模型正文落实什么 |
| --- | --- |
| 情绪或关系，如紧张、青涩或压迫 | 谁先察觉什么，视线看向谁，呼吸、表情、姿势或动作怎样变，最后停在哪个状态 |
| 运镜术语，如推镜、绕拍或拉焦 | 机位还是焦点在变化，从哪个位置出发，朝哪边、走多远或多快，最后露出什么 |
| 节奏词，如忽然、留一拍或余韵 | 动作的触发、加速或停留发生在哪个画面事件之后，以及这段时间仍可读到什么 |
| 切镜词，如接切、擦镜或声桥 | 前镜怎样结束、何时切、后镜第一幅看到什么，选择的接点怎样承接，见[硬切与过渡怎么选](camera-and-cutting.md#硬切与过渡怎么选) |

先完成可执行的改写，再成稿。只写「有电影感」「运镜流畅」「自然转场」时，补足看得见的机位变化、表演动作、空间或声源。按导演稿倒查正文是否把同一件事接起来。

## 一份时间表，两种输出

直接用于本机时，以 H3 的输入格式为准，用 Seedance 的结构化方法决定素材职责、镜头叙事和声音落点。要求同时交付时，用[双版本交付与海堤实例](../../short-video-supervisor/references/prompt-pair.md)从同一个镜头安排输出，避免改换模型格式时顺带改变场面设计。

| 项目 | Seedance 2.0 / 2.5 | 当前 1160 H3 四步 Turbo |
| --- | --- | --- |
| 分镜正文 | 2.0 优先用镜号，2.5 也可用连续整数秒时段。逐段说明画面、动作、机位和声音 | 有参考用 Ref2VA 六字段。纯文本第一行用 `integrated_multimodal_description: [Shot 1] ...`，用自然叙述安排同镜动作。实际换镜用递增镜号与单个切点。默认语言与封装见 [1160 规则](../../h3-visual-prompting/references/h3-formats.md#适配本机-1160) |
| 素材绑定 | 按实际入口展示的图片、视频和音频编号，逐项标注用途。首尾帧、编辑、延长等任务用相应模式 | 使用实际绑定的 `<Picture N>`、`<Video N>`、`<Audio N>` 及 1160 调度。按当前节点槽位顺序核对 |
| 动作与机位 | 为实际参考说清要继承的动作、运镜、节奏或视角。准确构图可评估首尾帧与关键帧模式 | 默认先测短镜头，验证同一动作和一条机位路径。切点、跨镜节拍需要精确时，把目标放在后期时间线 |
| 声音 | 每镜声音事件和全局音乐分别写清。生成或后期的安排依实际任务模式 | 关键同步事件写在镜头正文。底声与配乐用对应字段，后期用统一音乐和声音轨对齐 |

## 可复用填写模板

```text
全片目标｜时长／画幅／人物和场景／动作的最终结果
参考职责｜实际素材编号／只继承哪些特征／在第几镜使用
镜头 N｜成片时间范围／入镜姿态与承重脚／动作触发、轨迹、接触和结果
机位｜起点与高度／一条运动路径／结束景别／可见的近远地标变化
切点｜切前与切后的动作阶段／承重脚和朝向／下一镜增加的信息
声音｜底声／动作触发音／音乐重音／是否由后期对帧
```

写 Seedance 时，把全片目标和参考职责放在开头，按顺序写每镜的时间范围、动作、机位和事件声，最后写贯穿全段的环境和音乐。写 1160 H3 参考生视频时，把参考职责和允许变化的特征填进 `subject_definitions` 与 `retention_analysis`，整段结果放进 `summary`，把动作与机位合成写进 `detailed_description` 的镜头正文。纯文本模式将动作与机位放入 `integrated_multimodal_description`。声音按是否贯穿本段放进镜头正文、`overall_soundscape` 或 `non_diegetic_music`。独立生成时用本段经过的时间，成片时间留给剪辑。

## 示例：10 秒舞蹈动作接镜

这张表是成片时间线。音乐为 100 BPM，从第 0 秒起拍。H3 可分别提交三个片段，将 1160「每段视频时长」依次设为 4、5、4 秒，留出剪辑余量。一次提交多个块时，它们共用面板上的时长。第一个镜头交代入拍，中镜展示完整足位和快慢变化，末镜显示收势和空间。

| 成片时间 | 动作与衔接 | 运镜与切点 | 音乐和音效 |
| --- | --- | --- | --- |
| 0–3 秒 | 第 0.6 秒右脚侧点后踩实，两脚分开。第 3 秒屈膝，把重心落到双脚之间 | 全身慢弧移，结束在侧前方。切在双膝下沉 | 一条连续鼓点，右脚踩实给轻短的鞋声 |
