# 角色分工与交接

根据当前决定选职责。一个人可以兼任多项，交接记录可以合在同一份分镜表或制作单。用户只要求改标题、对白或提示词时，直接处理对应部分。

要按国内平台、短剧合作或国产案例优化各角色做法时，查阅[国内创作分工实践](china-role-practice.md)。里面按十项职责给出可交付的改动和参考出处。

## 每项职责解决什么

| 职责 | 何时介入 | 交付给下一步 |
| --- | --- | --- |
| 热点编辑与内容研究 | 需要找当下热点、核实老梗翻红、研究高流量案例时 | 来源与取数时间、榜单名次或可比指标、适用范围、可能的借势窗口及创作切入点 |
| 创意策划 | 从一个梗、热点或成熟题材延展为可拍的原创短片时 | 差异明确的几个创意、各自的首镜与包袱，推荐一个当前能完成的方案 |
| 编剧 | 确定短片故事、逐集冲突或修改一场戏 | 主角行动、冲突结果、结尾回报、对白及必须让观众看懂的信息 |
| 制片 | 开拍前、试播转连载、生成或后期超出可用时间时 | 需要先验证的镜头、实际制作成本、可复用素材、排期，以及范围缩减方案 |
| 导演 | 剧本拆成视听动作、复杂动作需要改拍法、试片无法传达叙事意图时 | 镜头表、表演与机位、信息揭示时机、必保镜头和可替代拍法 |
| 视觉美术 | 建立统一画风、人物或场景需要跨镜头复用时 | 可复用的角色、服装、道具、场景与光色参考，标明哪些特征需要固定 |
| 场记与连续性 | 同一角色跨镜、续集接上集、补拍或重生成时 | 前后镜比对及修正项，核对视线、动作接点、道具位置、服装和人物已经知道的信息 |
| 剪辑与声音 | 素材变成粗剪、要做横竖版、对白或节奏存在问题时 | 剪辑顺序、声音和字幕处理、补镜清单、成片版本及带时间码的验收意见 |
| 平台运营 | 准备抖音或 B 站投稿、复盘表现或要验证包装策略时 | 平台版标题、封面和简介，以及观察窗口、主要指标和下一轮测试项 |
| 发行与版权 | 使用第三方素材、准备商业交付或和红果等平台谈合作时 | 素材来源和使用范围、AI 声明、目标账号和版本、合同待核项。涉及收益时写明结算口径和授权范围的证据 |

## 在关键交接点做决定

- **选题到试播。** 内容研究把公开案例的观察交给编剧，编剧转成自己的故事动作。制片与导演找出最难验证、又决定故事是否成立的一镜。先做这一镜的试片，记录挑出可用镜头用了几次生成、多长时间。用户能用这些结果判断是否值得扩成整条或做连载。
- **分镜到素材。** 导演给出该镜头必须传达的信息，视觉美术给固定参考，场记核对相邻镜头的动作和道具。重生成时只标记受影响镜头及关联镜头。如果提示词仍难稳定，先沿用原叙事功能改拍法，例如把复杂交接动作改成道具特写与接收者反应。
- **粗剪到投稿。** 从观众视角完整看一遍，再按时间码写出最影响理解的画面、声音或字幕问题。优先修复情节难懂、音画问题和无法交付的素材，再打磨包装。平台运营核对标题和封面能否在成片兑现，发行与版权在涉及授权或平台合作时核对会影响交付的问题。两平台共用素材时，让每份文案、封面和字幕指向对应的成片版本。
- **上线到下一集。** 平台运营把掉点或反复出现的评论定位到具体段落，编剧或剪辑给出一项改动。制片评估补拍、重生成或改后期的时间成本。有多个合理解释时写明待验证项，并优先做最容易区分解释的改动。

如果一个项目有多项待确认内容，集中记录会影响下一步的几项。每项写清现状、可核查的依据、建议做法和对交付的影响。
