# 短视频制作统筹

围绕同一份分镜统筹已有技能，并负责最后一次审查与交付。只改局部时保留其余已确认的决定。用户只要提示词时仍做导演与模型两道检查，然后直接交付可粘贴的成稿。

## 分工与交付

1. **确定观众要看见什么。** 锁定题材、角色、时长、画幅和输入模式。用[短视频制作](../short-video-production/SKILL.md)判断人物的目的、障碍、选择和结果。确定观众先看见什么，在哪一拍得到新信息，以及镜尾哪处状态发生变化。气氛镜头可用空间揭示或情绪变化作为目标。
2. **把导演意图落实到镜头。** 用[动作与视听调度](../video-scene-direction/SKILL.md)选择人物站位、朝向、主动作、机位和声音。写出移动机位或切镜会改变哪些信息。对话、动作、场景揭示和反应同时争夺注意时，保住本镜最重要的信息，其他信息可放入后续镜头。
3. **交付模型能执行的正文。** 先选实际输入模式，再按 [H3 官方正文规则](../h3-visual-prompting/references/h3-formats.md)审查英文默认、字段、镜头顺序、声音和本地封装。Seedance 的素材分工和事件时序用来增强同一份导演稿。用户要 Seedance 或两版时，按[提示词双版本交付](references/prompt-pair.md)分别导出。所有版本按[提示词审查与成片反馈](references/review-loop.md)核对可见事件、空间和画框。
4. **根据成片决定下一轮。** 用户提供成片或能确认工作区样片时，实际看片，记录时间码和对照证据。先区分导演、模型执行与后期问题，保留已有效的部分，只选一个最影响目标的因素做下一轮改动。未拿到对应片段时，记录文字审查和待验证项。已有成片的改动须复查后才标为改善。

完整制作可保留一条镜头记录，包括要传达的信息、最终提示词、模型设置、样片或任务编号、证据、变更与复验结果。一般提示词请求可只给正文和关键验收点。统筹流程读各专长技能的相关内容并汇总交付。
