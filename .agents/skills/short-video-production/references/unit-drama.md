# 单元剧与角色预设

用于固定主角或常驻小队、同一世界里的独立故事。每集让新观众看懂当前处境，并在当集处理主要冲突。角色关系可以渐进变化，重要变化要同步到系列设定。用户只要求搭建基础时，交付下面的空白模板。

## 系列设定卡

按项目需要填写。把会影响长期创作的决定写在这里，单集可以变动的内容留给单集卡。

| 字段 | 内容 |
| --- | --- |
| 系列名、类型、目标观众 |  |
| 每集的观看回报 |  |
| 主角长期处境与反复遇到问题的原因 |  |
| 世界规则与例外 |  |
| 常驻角色、关系、可复用场景和道具 |  |
| 单集更换的要素与适合观察的热点 |  |
| 剧情模式和连续性范围 |  |
| 画风、声场、画幅与制作预算 |  |

检查系列能否从不同的来客、物件、任务或限制中自然产生不同故事。试着从三个方向列出可替换的要素，避免每集只更换道具名称就重复同一个包袱。常驻角色数量根据叙事和制作需要确定。

## 角色预设卡

| 字段 | 内容 |
| --- | --- |
| 角色编号、姓名和身份 |  |
| 长期目标、弱点、做事方式 |  |
| 面对麻烦时常作的选择 |  |
| 常用动作、说话节奏与情绪范围 |  |
| 稳定外形描述 |  |
| 常用服装、道具与可变范围 |  |
| 参考图、声音素材编号及使用范围 |  |
| 与其他常驻角色的关系 |  |
| 最近确认的设定版本 |  |

把人物写成会主动选择的人。单集设计要让选择改变局面，观众才会记住这个角色。给 ComfyUI 的固定外形描述宜简短，聚焦脸型、发型、体态、标志性服饰等可见特征。另写本镜的动作、机位和情绪。素材准备时优先锁定同一角色的正面、四分之三侧面和常用服装，按工作流实际支持选择参考方式。种子用于记录和复现一次生成，角色一致主要靠稳定参考图、人物描述和逐镜验收。

## 单集卡

| 字段 | 内容 |
| --- | --- |
| 集号、标题、是否可独立观看 |  |
| 本集来客、物件、任务或规则 |  |
| 开场发生的异常 |  |
| 主角目标和主动选择 |  |
| 选择带来的后果与转折 |  |
| 当集解决的冲突与结尾回报 |  |
| 要沿用、变化或恢复的设定 |  |
| 热点来源及原创切入点（如适用） |  |
| 要复用的场景、参考素材和新增镜头 |  |

将单集当成观众第一次点开的作品。检查开场是否交代所需信息、转折是否由当集已展示的规则或选择引起、结尾是否兑现开头。可用角色习惯或固定场景建立系列辨识度。热点可以成为当集的道具、规则、任务或环境变化，主角的行为与系列基调以已确认设定为准。

## 连续性与制作记录

- 需要跨集复用时，用角色编号、场景编号和参考素材编号标注分镜。记录每集实际使用的角色设定版本、常驻场景、道具状态和关系变化。
- 审片抽查首帧、主角正脸、相邻镜头动作和最后一镜。标明可接受的表情或换装变化，以及要补录或重生成的脸型、服装、道具和音色偏差。
- 制作流程沿用[制作与运营手册](production-playbook.md)。题材需要借势时，按[热点雷达与原创选题](hotspot-radar.md)核对当期证据，再把切入点填到单集卡。
