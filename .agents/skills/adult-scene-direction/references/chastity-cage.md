# 贞操锁 / Chastity Cage 写法

## 核心要求
贞操锁是金属/塑料装置，必须保持形状、材质、锁具细节在运动中不变形、不消失。

## 推荐触发与描述
- 基础词：`chastity cage`, `chastity device`, `locked chastity cage`
- 材质与颜色：`metal chastity cage`, `pink plastic chastity cage`, `transparent chastity cage`, `flat chastity cage`
- 细节：`padlock`, `small padlock`, `testicles visible below the cage`, `urethral tube`（如有）
- 状态：`securely locked`, `the cage remains firmly in place and correctly shaped`

## 正文示例
```
He wears a metal chastity cage that fully encloses his penis, with the testicles visible below. The cage stays correctly shaped, locked and in place throughout the movement, with realistic metal reflections.
```

## 与参考 / LoRA
- 社区有专门 H3 / Illustrious / Pony 的 chastity LoRA（如 ST-REAL-H3 CAGE-CHASTITY）。
- 无 LoRA 时：用清晰局部参考图 + 多次正向描述 “the chastity cage remains firmly locked and correctly shaped”。
- 避免模型把锁画成模糊块或消失：在 end state 再次确认。
