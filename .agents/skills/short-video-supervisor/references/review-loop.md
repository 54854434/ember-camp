# 提示词审查与成片反馈

## 按场面选择技法

先判断本片观众需要先看懂什么、哪一刻改变判断、最后看见什么结果。短片可以从动作已经发生的瞬间开场，必要的空间和人物关系跟着运动交代。用户提供写法参考时，先按[样稿拆解方法](../../video-scene-direction/references/visual-style-transfer.md#拆解结构化提示词与分镜样稿)确定要借鉴的技法。再按实际发生的事读下面对应资料。使用一项技法时，先确定它会改变哪个镜头的哪一处画面或声音。

| 片段出现的需求 | 优先阅读 | 成稿中要找得到的证据 |
| --- | --- | --- |
| 两人以上交锋、交接或换位 | [动作与局势变化](../../video-scene-direction/references/action-direction.md#高速动作与场面升级)、[人物走位](../../video-scene-direction/references/performance-and-blocking.md) | 起势有来路，回应有对象，结果改变双方距离、持物或通路。换位过程在画内，或者切前切后有同一动作或地标可接 |
| 连续跟拍、关键揭晓或多镜剪接 | [摄影与切镜](../../video-scene-direction/references/camera-and-cutting.md)、[镜头技法与应用](../../short-video-production/references/camera-and-editing.md) | 机位起点、触发、路径和落幅可以推导。切后出现新的可读信息，保留足以接续的动作、视线、构图或声场 |
| 异常光效、环境交互、局部破坏或大场面 | [特效与空间](../../video-scene-direction/references/cinematic-shot-plan.md#高密度动作与特效分镜)、[场景连续性](../../video-scene-direction/references/action-direction.md#场景连续性与破坏) | 能看见效果来源和传播。局部损伤有边界，整体规模有参照。触发、受影响的表面、残留状态和下一镜的证明都有对应画面 |
| 真人表演、剧情对白或重要的听者反应 | [走位与真人表演](../../video-scene-direction/references/performance-and-blocking.md#让表演有具体的触发)、[对白时长](../../video-scene-direction/references/music-and-sound.md#对白时长与切镜) | 说话人、对白原文、出声与沉默正确。反应由具体事件触发，在相应景别可见 |
| 声音负责冲击、提示或跨镜衔接 | [声音与卡拍](../../video-scene-direction/references/music-and-sound.md) | 能找出声音开始的接触或事件，知道哪层延续、哪层该退下。需要对帧时把准确落点交给时间线 |
| 角色、动物、道具或场景必须稳定 | [主体外形和场景交互](../../h3-visual-prompting/references/shot-enhancement.md)、[H3 素材职责](../../h3-visual-prompting/references/h3-formats.md) | 角色或场景在镜头里有稳定称呼和可见识别点。各参考对应实际素材，只继承它负责的特征 |

按本镜职责取舍。静态镜头可用构图和表演，单人片段未必需要正反打。高密度需求按[场面复杂度](../../video-scene-direction/references/prompt-enhancement.md#根据场面复杂度增加细节)保留关键交互与节奏变化。

## 出稿前分别验收导演与模型

| 检查 | 可交付的标准 |
| --- | --- |
| 导演意图 | 能说清观众在开头、中段和结尾分别知道什么。动作镜头交代发起与后果，氛围镜头交代该观察的空间或情绪变化 |
| 画面选择 | 能指出机位移动或剪切露出了什么、形成什么对比、怎样改变注意力。主体、威胁和反应的位置有根据，关键信息处于景别覆盖范围 |
| 模型语言 | 把「坚定」「危机」「震撼」翻译成演员姿态、视线、道具、空间比例、声响或光影。关键事件写清主体做了什么、接触或触发点、随后变化的是谁 |
| 场景交互 | 必须出现的道具、环境响应和独立背景运动，在发生的镜头正文里有可见触发或起始条件、可辨认的运动和后续状态。检查变化发生的位置、受影响的对象和画框是否覆盖它。见 [H3 场景交互写法](../../h3-visual-prompting/references/shot-enhancement.md#把场景交互写进镜头正文) |
| 时空关系 | 相邻时间段顺序一致，人体朝向与摄影机路径有独立的空间参照，镜头能保住需要看清的手、脚和表情。复杂移动镜头按首帧、转折点、接触或揭晓帧和尾帧核对。环境变化与拟音有对应的触发动作 |
| H3 输入 | 先确认 T2VA、Ref2VA 或首尾帧模式。按交付入口核对正文语言、字段、镜头切点、环境声和配乐。1160 中文交付还要检查完整分段和真实素材槽。见 [H3 官方结构与本机输入](../../h3-visual-prompting/references/h3-formats.md) |

### 从成稿倒查镜头

1. 按片段实际有效的正文走一遍。对每个关键事件，在内部对应「观众该看到或听到的证据 → 负责的镜头 → 模型收到的具体句子」。只出现在大纲、元数据、摘要或参考图里的动态事件，补写到发生的镜头。镜头首现主体时按景别写足定位和可辨特征。复杂场面或要求全程紧凑时，依据[逐秒画面进程](../../video-scene-direction/references/prompt-enhancement.md#逐秒检查画面进程)读一遍首尾和每个过渡，找出跳过触发、反应提前、关键结果一闪而过或中段没有接续的问题。
2. 分开核对人物路线与摄影机路径，随后检查它们在画面里能同时成立。逐个切点对照前一镜最后可见的动作、声响或形状与后一镜最先看到的状态。关键物件细节与全景规模需要不同画框时，把结果先放进可辨认的景别，再揭示全貌。
3. 将每一关键变化的写法横向核对到摘要、保留分析、逐镜正文和声音。出现同一部件在一处只写局部变化、另一处暗示整体变化时，改成一致的部位、范围与结果。素材切换或一镜多拍时另查资产名称、引用映射与可用时长。
4. 紧张节奏让动作、反应、机位揭晓或声音延续接替主导画面。镜头拥挤时优先让观众读清关键接触或结果，再加入能帮助阅读的动态层。凡是找不到对应正文、过程互相冲突或画框看不到的关键要求，修正后再交付。

内部核查可用短表或逐句复读。格式检查验证字段和调度，成片遵循度需要样片。用户只要提示词时，把修正写进成稿，按约定交付即可。

### 从导演稿到模型正文

导演稿「让观众发现女人守的是避难者，并在浪落下后看到守护结果」。写给模型时，用空间与动作交代这层关系，例如「女人身后紧邻一道铁闸。栏杆间透出一盏暖黄色提灯，几双手抓着内侧栏杆。女人听见闸门响动，侧跨半步站到海浪与铁闸之间。浪从堤外侧落下。镜头继续横移，铁闸仍闭合，灯光仍亮着」。实际成稿还要写明可见的景别、机位路径和片段时长。多个重要状态塞进一镜时，先决定这一镜必须交代哪一个。

## 拿到样片后

需要评估事件顺序、可见交接、运镜与声音同步时，先用[逐事件验收表](event-validation.md)写出每项的证据，再比对样片的对应时间窗。

1. 核对版本。优先用用户提供的文件或工作流任务编号。通过文件名、实际画面、时长或有对应关系的提示词确认。同一文件名或时间接近只用于找候选片。
2. 先看片判断观众能否读懂目标，再检查关键动作和切点。记录「时间码、预期、观察、证据」。抽帧可核对构图、道具、首中尾和视差。实际连续播放或连续取帧核对切镜、动作节奏和闪变。对白、卡拍或拟音需要实际试听。只有部分证据时标明覆盖范围。
3. 把问题归到可改变的环节。生成结果按指令出现但观众仍看不懂，先改构图、表演或叙事安排。画面遗漏明确指令，先改可见线索、参考锚点或单段动作密度。画面正确但卡点偏差，先修剪辑或声音。证据不足以确定原因时，写成假设。
4. 给最关键的一处改动及回归条件。做 A/B 时记录同一工作流、模型与 LoRA、随机种子、分辨率、时长、参考输入、采样参数。改变工作流时，把它单独作为变量。先确认 B 改善目标，再检查 A 已通过的构图、动作或声音是否退化。没有 B 或设置无法确认时，保留「待复验」。

### 核对提示词遵循度

- 按实际送入生成节点的正文列出检查项，分别核对主体可见特征、关键动作与因果、固定地标、机位和切点、末态及声音。每项记为符合、部分符合、遗漏或无法判断，并写可见或可听的证据及时间。正文没有指定的外观细节，可记录为下一次创作选择。
- 切镜先用逐段画面定位，再看预计切点前后的相邻帧，分别记录实际是否换机位、切点偏差和末镜是否揭示预期范围。只凭等间隔抽帧或自动场景检测时，对是否实际切镜保留判断。声音项经试听才判定。样片无法对应实际提示词、语言或参数时，按样片记录执行情况，保留版本差异待核实。

| 当前证据 | 反馈可写到哪里 |
| --- | --- |
| 只有提示词 | 指出文字设计哪里可能失效，给下一轮需要观察的证据 |
| 已确认对应的样片 | 写实际时间码和可见或可听的问题，再给一个可执行改动 |
| 可比的 A/B 样片 | 就相同时间段报告改善、持平或退化，决定保留哪一版 |

### 比较一句话增强的收益

- A 是原始简述按 H3 格式封装的基线，B 是同一简述按技能拍法增强的版本。两版必须使用相同 H3 工作流、生成模式、参数与配对种子。用 1160 穿透模式放入两份已格式化的正文，避免再次改写。C 可用同一句简述、时长、画幅和参考素材生成的即梦原片，供比较最终观感。
- 事先确定评分项。原意与必要事件须通过，再对画面看点、运镜叙事、动作与环境因果、节奏与声画和场景连贯逐项判断。每项可用 0（缺失或明显错误）、1（能辨认）、2（清楚且有效），结合时间码记录证据。题材没有相关设计的项可在生成前统一换掉或标为不适用。
- 需要报告相对目标时，若即梦比分高于 H3 基线，用 `(B − A) / (C − A)` 表示本机增强缩小了多少成片差距。多个题材用同一规则，并保持每组设置一致，报告原始分数、样本数和变动。A/B 用来归因 H3 提示词，C 用来观察整套平台的输出差异。缺少可比样片、原意失败或 C 未高于 A 时，保留原始观察与分数。
- 相对分数用于追踪差距。目标是尽可能接近参考成片，后续优先处理能定位且影响最大的差距。复杂任务单独核对多主体衔接、空间转换和层叠环境响应，避免总分掩盖关键动作遗漏。要比较细节密度时，在 H3 上固定故事、镜头与设置，对照简述与展开写法。保留能改善成片的细节。
