# 人物走位与真人表演

## 先把人放进同一个空间

1. 从实际首帧、场景图或预演确定现有地标和可通行空间。分别写场景中的位置与当前画面的位置。用「靠门的桌角」等固定物定位，把画面左、右、前、后从实际机位推导出来。单张图以外的结构按已知布局补足，重要的推断在分镜稿标明。
2. 给每个主要人物记录开镜与收镜的落脚点、躯干和脚尖朝向、头和视线目标、持物与承重状态。涉及左右手或不对称造型时，以人物本人为准。多人同框时写清前后层次、临时遮挡及谁在画外。
3. 用可看见的触发安排走位。谁先起步、沿哪条路线经过哪个地标、从谁的身前或身后通过、在哪儿停下。递物、开门、落座先写接触点和承担重量的一方，再写新的持有者或姿态。遮挡结束时保持同一人物、路线与物件状态。
4. 换机位时从原有地标重新推导画面左右。用[摄影与切镜调度](camera-and-cutting.md)核对正反打、行进方向和动作是否接在同一阶段。多人路线不易理解时，分镜另附简明俯视草图，标注落脚点、机位、运动箭头和朝向。

## 从平面走位到可生成首帧

- **俯视平面图用于排戏。** 把门窗、家具、落脚点、路线及机位画在同一平面，检查通路、遮挡和跨轴。然后站到实际机位朝向重算画面左右、前后、视觉大小和裁切。先明确第一帧已经入画的人、还在画外的人，以及后者因何时、沿何路线入画。
- **机位视角图用于核对画框。** 复杂同框可从实际机位画一张取景示意或取预演截图。逐人核对可见部位、头和躯干朝向、视线落点、道具相对手和身体的位置，以及与固定地标的接触关系。修改机位或站位后，以原场景和新版调度重新投影。使用中的素材标记版本，确保正文引用的是新构图。
- **实际生成用与入口匹配的参考。** 需要首帧准确时，先用该机位制作具备最终人物和环境外观的首帧，再走对应的首帧入口。对仅用于排戏的色线、字母和箭头，用文字把位置、朝向与尺度转成真实地标关系。单独给模型绑定机位示意图属于待测做法，适用边界见[走位图研究记录](../../short-video-production/references/technique-findings.md#走位图到底能控制什么)。

## 在切点对齐人物站位

- 连续时空内，每个关键切点先定一个由两镜共享的状态。逐人记下相对固定地标的落脚点和前后关系、身体朝向、动作或承重阶段、手里的物件。按下节选择需要继承的状态。有人被挡住时，记录遮挡前的真实位置和重新入画的路径。
- 前镜写怎样达到切点，后镜从新机位接动作自然向前的紧邻阶段。静止的人保留落脚点，行进中的人沿同一路线继续，落脚、接触与发力在单一连续时空只发生一次。按切前瞬间、切点和切后瞬间检查三处。画面左右随取景重算，衣摆、持物或地标可证明接上。
- 当步态、落地或腿足展示影响剪接时，前镜落幅和后镜起幅分别填写「人物自己的左脚在哪、右脚在哪 → 哪只脚承重 → 哪只脚在移动，以及脚跟或前脚掌是否接触 → 下一次重心转移」。两脚用同一个固定地标定位，沿实际行进方向检查哪只脚更靠前。换机位时单独重算画面左右。需要换前后脚时，让观众看见完成换位的那一步。
- 支撑状态在切后读不清、两脚被裁切或正在空中交叉时，先判断这一下是否必须切。精确步态优先保留完整的接触和承重过程在同一镜。需要切时，可以移到迈步前或落地站稳后；如果必须接在动作中，写清正在移动的那只脚、支撑脚的固定落点及两侧共同可见的地标，并按[实际帧输入](../../h3-visual-prompting/references/h3-formats.md#跨生成段的实际帧输入)评估是否需要使用已经验收的接点帧。
- 复杂场面分别记录世界地标与方向、人物自身左右、摄影机取景得到的画面方向。水平位移、升降和转身各自延续，改变方向要有看得见的原因。摄影机滚转可以转动画框，人物、雾、水和摆动物仍依既定世界重力。相邻镜持续继承伤损、湿痕、道具归属和未落定的效果。
- 群戏、追逐、交锋或道具插镜容易串位时，在后一镜开头保留关键人物和一个可对照的地标。需要先拍局部时，在切前明确看清关键人物位置，把重新入画安排在地标可辨的构图中。跨轴或明显跳时用画面重新建立关系，按剧本写清新的位置或时间。
- 对话离场先按人物真实路线判断视点。跟着留下者的视线看离开的人，可以见其走远的背影；正面拍留下者的反应时，若机位在离去方向，对方应越过机位、在它旁边或已出画。并行行动用共同事件、声音或可确认的时间线索说明同步；跳时用画中状态变化交代省去的时间。
- 排查时对比实际切点前后相邻画面，必要时多看几帧。依据同一地标、衣物固定细节或道具可辨部位，区分取景、遮挡和实位变化。核对两脚接触、持物手和佩戴点时以人物自身左右为准。若两侧都找不到足够证据，记录该项无法判断。需要更强控制时，按实际入口评估同一摆位的接镜关键帧、运动参考或分段剪辑。

### 逐项核对容易穿帮的状态

只记录会影响剪接、叙事或辨认的项目。对相邻镜头或生成段，用「前镜最后可见状态｜切点或触发｜后镜第一可见状态」核对。变化如果在画外发生且剧情需要观众理解，用可听的触发、出入画路线或后续画面交代。

| 项目 | 道具、人物和场景要继承的内容 |
| --- | --- |
| 人物站位与朝向 | 相对同一固定地标和他人的位置、距离、前后层次、身体和目光朝向、哪边出入画。改变机位后重算画框里的位置；人物移位时交代经过的路线或省略过的时间 |
| 手脚、支撑与接触 | 哪只手正在抓、扶或推，哪只脚承重，接触的是哪一部位。检查下个动作能否从当前姿态开始，同一只手是否被要求同时完成互斥动作 |
| 手持道具与交接 | 是哪一件、由谁的哪只手握住、握在哪里、关键一端朝哪边。递接时写清接手、承重和放手的顺序；收纳、掉落或移交后，在重入画时延续新的归属与位置 |
| 佩戴或挂置道具 | 是谁的哪一侧肩、腕、腰，还是挂在布景的哪个挂钩、横杆或门沿。标明固定点和悬垂方向。轻晃只改变悬垂部分；换侧、脱落或取下需要触发和新落点 |
| 放置道具与布景状态 | 道具接触哪个表面、靠哪个地标，朝向及敞开、闭合、亮灭、溅湿、损伤等状态。取景裁掉门、家具或道具时，保留其实际位置；再次拍到时继承已发生的变化 |

优先把易露馅的接触点和关键地标留在两边可辨的构图里。动作顺序或持物状态无法从该切点成立时，改在接触前或动作收稳后切，或在同一镜拍完关键变化。需要精确继承已有画面时，按实际工作流选择首帧或首尾帧。正文用可见状态说明变化，例如写明哪只手仍握着提环、挂钩从哪一侧进入提环，手松开后提环由谁支撑。

## 双脚入画与落点

- 需要清楚拍到双脚时，先用人物自身左、右确定各自的支撑和落脚位置，再用地面接缝、台阶边缘或相邻石面区分两处落点。普通迈步保持适合动作的自然横向间距，移动脚沿自身一侧前进。原支撑脚保留接触，待新落脚建立支撑后再完成换重。只在动作本身要求交叉时设计交叉，并写明哪只脚从哪一侧通过、哪只脚承重。
- 以机位视角检查抬脚、移动脚经过承重脚附近和落地时的轮廓。需要两脚都可辨时，保留画框余量并找能看清接触位置的斜侧机位；过分贴地或纯侧视导致轮廓叠合时，微调机位方位或高度。将需要保持的两脚间距、落点和可见性写进正文。走位自然产生短时遮挡时，写清哪只脚重新露出的位置。
- 样片里两脚投影暂时叠在一起时，连看关键帧确认是否各自沿原线路移动并在预期位置露出。出现脚互穿、轮廓粘成一处或落到同一点，先找首次偏差。落脚逻辑正确而镜头看不清时调机位；路线本身重合时改落点或缩短动作，并复查正反脚与重心。

## 让关键接触在画面里可见

- 手递物、脚落地、手按到机关等决定叙事的接触，要核对接触前、接触时和脱离后这三处是否可见。用实际机位检查两只手或两只脚、衣摆、前景和道具边缘会不会在关键时刻叠到一起。需要看清时，优先调整机位、接触高度或动作节奏；在关键落点发生后安排衣料掠过或前景遮挡。
- 设计遮挡时，写清遮挡物从哪里进入和离开、谁在它的哪一侧，以及重新出现时原有位置、持物与接触状态如何延续。动作发生在遮挡后方且需要观众理解时，可以用一次清楚的同步声提示，再用重新入画后的状态证明结果。关键持物或支撑关系无法读清时，给镜头留出能看清的短停顿。

## 让表演有具体的触发

- 从角色此刻想做的事出发。挑一两个在当前景别能读到的反应，写清「看到或听到什么 → 原动作如何变化 → 看向哪里或接着做什么」。自然停顿、目光停留或重心变化都可传递情绪。镜头太远时优先用姿势与走位表现。
- 可见动作写受力顺序与收势。走路需要实际迈步和落脚，落座经由重心转移与座面接触，手拿起道具前先明确抓住的位置。头、肩、衣料或发丝按实际速度和重量产生后续运动。
- 对白保留说话人的原文和语气。听者用注视、轻微换气或短暂停手表现听到了什么，保持自己的嘴唇自然。台词未引出反应时，表演维持当下的注意力和动作。画外音、旁白与内心独白单列。
- 真人质感优先使用素材已有的五官比例、年龄、肤色和衣服结构。按景别选可见的皮肤或织物细节，保留自然的细小不对称。光位从窗、灯或其他可辨认的来源建立，转身和移动时阴影随之变化。避免给呼吸、眨眼和表情写机械循环。

## 交付与排查

首帧词描述可停住的起始姿态，视频正文按动作实际先后写。用于白模时优先落地站位、路线、遮挡、道具接触与摄影机衔接，有表演参考再说明视线或节奏的控制用途。对白和拟音另列，估时见[对白时长与切镜](music-and-sound.md#对白时长与切镜)。

需要单独交付站位设计时，逐镜写「机位所在侧和朝向 → 人物相对固定地标的位置和视线 → 走位触发及经过点 → 落脚点、持物与接镜」。要首帧图时，按同一机位把这一刻的全部必要状态写成可独立使用的生图词，含人物名、可见识别点、相对位置、手与道具以及光位。双人正反打按同侧机位分别重算视线。需要首尾帧时，在可走通的路线中先安排中途转身、接触、换手或遮挡的时机，再写怎样到达实际尾帧。要俯视稿时标出动线、朝向与机位，按所需交付。

有成片时找首次偏差，说明看到的人物位置、朝向、视线或接触发生了什么。再分辨是首帧条件不符、走位和镜头指令重叠、遮挡后的重新入画失败，还是实际成片执行偏差。改对应镜头，使用同一地标或动作验收。
