# 动作指导与编排

把用户的动作意图拆成可看见的变化。舞蹈优先交代承重脚、节拍和方向。奇幻交锋优先交代谁先发起、对方如何应对，以及空间和目标最终怎样改变。

## 动作从哪里开始，怎么结束

| 字段 | 具体要写什么 |
| --- | --- |
| 起始姿势 | 人站在哪里，面向哪一个地标，哪只脚承重，双手和道具在哪 |
| 预备与触发 | 重心先落到哪、眼神先看哪、动作由鼓点、来球、响声还是另一人引发 |
| 动作轨迹 | 哪一部分先动、往哪走、快慢和幅度，其他部位保持怎样的姿势 |
| 接触与反馈 | 此刻有没有踩地、抓住、交接或碰撞。接触点之后谁改变方向，哪个物体跟着动 |
| 出镜状态 | 最终落脚、停顿、人物朝向、道具去向，以及下一镜从哪一个动作阶段开始 |

- 舞蹈短段先设计一个完整动作句。常用结构是入拍、基础动作、节奏变化、收势。动作编排要能确定重心从哪只脚转到哪只脚，双脚留在原位的舞步也要写哪部分在带动。主动作执行后，再加臂线、头发、衣角等次级动作。
- 两人互动先画出 A、B 和物件的初始位置。明确谁发起、谁接收、物件何时离开原本的手。关键接触可以放在同一镜，也可用接触前后各自清楚的画面和声音剪接。
- 两个主体先后碰同一个物件时，分开写可验收的状态。先写等待的一方停在哪个地标、和物件隔多远，接着写主动的一方从哪一侧触到物件，最后写另一方看见接触后怎么动。接触帧要同时看清物件、主动方和另一方留下的空隙。示例见[最后一块饼干](../../h3-visual-prompting/references/examples/biscuit-1160.txt)。
- 奇幻战斗先给可见的目标和障碍，再写「发起 → 回应 → 结果」。一个高潮动作让观众看清起势、效果到达和造成的变化。背景效果跟随同一因果，例如冲击先卷起近处布条，再推动远处水面。多人混战时先固定主视点和方向。
- 离开人物或切换机位前留出下一镜能接的动作阶段。补生成时截取合格末帧核对脚位、肩向、手和物件状态。把首尾帧作为构图锚点时，核对所用工作流是否真正接受这类输入。

## 高速动作与场面升级

- **按观众需要分配时间。** 先为关键转折、高潮和结果留时间，再安排铺垫和连续交锋。每镜围绕一个观众必须看懂的动作或局势变化。用户指定的关键攻防分别交代，重复动作可以概述。短段给关键接触留出可读的一拍。镜头数量和时长按动作复杂度、用户目标和生成入口决定。
- **用攻防局势设计变化。** 用距离、高低、遮挡或场景障碍改变双方处境。写清谁发起、对方如何回应、动作结束时谁占优势。若有决定结局的道具、能力或地形，提前让观众看见它的用途或位置。多人同镜时给主交锋留出画面，其余角色有可辨认的站位和状态。
- **用状态接镜。** 切前确定双方位置、朝向、动作阶段和道具归属。切后承接这些状态。换边或越轴时，通过可见走位、连续运镜或清楚的重新定位构图交代方向变化。服装变化、脱手道具、受损布景和仍可见的特效残留按叙事延续到后镜。
- **让画框覆盖动作幅度。** 长道具、大范围位移或腾空，先确认人物和轨迹的关键部分在画内。竖屏可用纵深、高低差或窄通道组织运动。观众需要重新定位时给全景，关键接触与反应需要看清时再收紧。特效与机位搭配见[高密度动作与特效分镜](cinematic-shot-plan.md#高密度动作与特效分镜)。

## 场景连续性与破坏

1. **用固定地标交代空间。** 开场用可辨认的地标确定人物、布景和机位的相对位置。来路或退路影响叙事时，让入口和相连的地面在开场与收尾都能辨认。换机位时交代同一地标在新构图中的位置，并接续上一镜结束时的布景状态。
2. **写清实体怎样改变。** 短镜优先指定一个主要受击部件，写明位置、完好时的形状、接触点、受击变化和残骸去向。让相邻的固定结构提供定位参照。给光效和烟尘留出散开的时间，在尾帧或下一镜呈现可辨认的损伤，并让后续镜头延续该状态。
3. **让机位有条件拍到变化。** 场景容易漂移时，优先采用能同时保住地标、撞击点和结果的连续运动路径。需要换机位时用同一布景参考辅助定位。首尾构图有严格要求时，确认所用工作流可接入真实首尾帧。按[逐事件审查](../../short-video-supervisor/references/event-validation.md)核对成片。

## 看片时先查动作本身

先静音看一遍，再带音乐看一遍。按时间码确认起势、承重或接触、结果和出镜姿态。跳舞的脚滑、动作振幅不稳、舞步与鼓点不合分别归因。先把缺失的动作写成一拍能完成的变化，动作已正确时再检查机位和节拍。涉及具体舞种并且动作专业性重要时，用可靠的舞者示范或自录动作参考核对。
