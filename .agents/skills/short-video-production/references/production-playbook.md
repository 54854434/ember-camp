# 制作与运营手册

## 试播与连载开发

- 用一句话明确受众、人物困境和观看回报。将开头承诺、主角选择和结尾结果对应到具体画面。检查删掉解释性对白后，观众还能否顺着动作理解因果。
- 试播覆盖最关键的制作风险，比如同一角色跨镜头是否稳定、关键动作能否生成、对白和背景声是否清楚。一次只检验几个直接影响后续选题和成本的假设。
- 连载启动时明确每集解决的问题、跨集悬念和人物变化。为需要复用的角色保存参考图、服装道具、声音设定和不能变化的特征。集末记录人物所在位置、掌握的信息和已兑现的伏笔。修改前集时检查后续依赖的情节。
- 扩产前记录每个可用镜头的生成尝试数、挑片和后期耗时，标出最难稳定复现的镜头。用实际产能决定单集长度、更新节奏和制作规模。

## 逐镜交付

根据任务所需选用字段。用户要求整条分镜时，让剪辑人员能够按表拼出全片。

| 字段 | 交付内容 |
| --- | --- |
| 镜号与时间码 | 镜头起止、镜头时长、顺接位置 |
| 剧情与表演 | 这一镜让观众看懂什么，演员或角色做什么 |
| 画面 | 构图、景别、机位、运动、人物和道具的进出画面 |
| 连续性 | 参考素材编号、动作起点与终点、视线方向、服装和光线 |
| 声音 | 对白、环境声、音效或音乐，注明画外音与声音进入时机 |
| 生成与后期 | 可粘贴提示词、画幅、目标时长、需要后期加入的字和合成元素 |
| 验收 | 关键动作是否完成，前后镜是否接得上，画面和声音有哪些具体缺陷 |

生成失败时先诊断原因。角色漂移先固定参考素材和镜头条件，动作断裂先简化一个镜头内的动作，口型难稳定时调整为旁白、画外音或反打。每次优先调整一个主要变量。需要复现时记录工作流版本、主模型、参考素材编号、种子、画幅、时长和输出文件。只在本地制作记录中保存实际运行参数与素材位置，供下一轮复用。

## 投稿与复盘

- 全片播放检查开头、关键转折和尾帧。验收画幅与字幕安全区、人物连贯性、音画同步、对话可懂度及手机小屏可读性。视频、封面、字幕、文案和平台声明应对应同一个成片版本。
- 先写要验证的问题及主要指标，再确定复盘窗口。看标题和封面需要曝光与点击数据时注明流量入口；看开场用可用的早期留存；看叙事用掉点时间码、平均观看时长及完播；看系列意愿结合关注和具体评论内容。
- 尽量使用同平台、相近时长、近似流量来源、同一统计窗口的历史稿件作基线。有曲线时把最明显的掉点对回成片，核对前一段观众已经得到什么信息。对低样本和不同口径的数据说明限制。
- 每轮优先测试一个版本差异，例如用角色行动作为首帧。记录版本、上线时间、统计窗口、指标定义、观察结果及下一步。播放量、创作激励、广告商单和版权分账分别记录实际结算方式和已知条件。
