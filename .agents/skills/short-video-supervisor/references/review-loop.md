# 提示词审查与成片反馈

## 两轮调度与终审

### 第一轮从用户意图分派

1. 提取「用户锁定」「为取得目标必须拍出来」「可交给模型发挥」三类信息。锁定时长、画幅、原文对白、素材职责和指定结果。把「有电影感、节奏别掉、人物要稳」等要求改写为可从样片判断的效果，如「贴地横移露出入口」「从起势、接触到回稳一直有可跟随的重点」「切后从同一个地标接人物动作」。
2. 按[场面选择技法](#按场面选择技法)判断本轮需要哪些专长，并实际打开相关资料。若当前入口已完成分派，沿用已有决定，补齐本轮缺项。纯排版只核对原文与格式，局部修改核对受影响的前后镜、声画及素材。
3. 内部为关键要求保留「预期观感 → 选用技法 → 段/镜 → 可见或可听证据」。新写或重写完整 H3 段按[四阶段成稿](../../video-scene-direction/references/prompt-enhancement.md#h3-四阶段成稿)分别形成导演稿与模型执行稿，逐拍核对后才转成英文。同一事件的动作、摄影与声音共用同一触发。冲突按用户明示要求、可见关键事件、辅助风格的顺序修订。

### 第二轮只从实际生效的正文重建画面

完成初稿后，用[成稿倒查](#从成稿倒查镜头)从实际模型输入和已绑定素材重建画面。逐项标记「有明确证据」「缺失」「冲突」，实际执行另记「需成片验证」。先修缺失和冲突，再复查受影响的接点与素材。同一交付只做一轮完整终审，由当前入口负责。

交付从生图、表演到导演的完整分镜，或用户反复遇到同一类 H3 偏差时，按[资产表演与摄影的联合核对](production-review.md#资产表演与摄影的联合核对)核对每项硬要求的生效位置。主张正文用了这些技法时，能定位到生成段、镜号、实际句子或所接的真实素材。

用户只要提示词时，交付正文。问「用了哪些技能」「有没有审查」时，给出参加的领域、对应镜号、实际采用及已修的一项。只有确实打开资料并把手法落实到正文，才说明用了它。文字终审确认的是指令覆盖、可读性与结构；成片效果等样片的画面声音核对。

## 按场面选择技法

先判断本片观众需要先看懂什么、哪一刻改变判断、最后看见什么结果。短片可以从动作已经发生的瞬间开场，必要的空间和人物关系跟着运动交代。用户提供写法参考时，先按[样稿拆解方法](../../video-scene-direction/references/visual-style-transfer.md#拆解结构化提示词与分镜样稿)确定要借鉴的技法。再按实际发生的事读下面对应资料。使用一项技法时，先确定它会改变哪个镜头的哪一处画面或声音。

| 片段出现的需求 | 优先阅读 | 成稿中要找得到的证据 |
| --- | --- | --- |
| 一句话扩写、缺关键转折或镜尾没有结果 | [创意增强](../../video-scene-direction/references/prompt-enhancement.md#一句话创意的自动增强)、[短视频编剧](../../short-video-production/references/screenwriting.md) | 新增细节服务原意。动作或反应有来由，镜尾出现结果、选择或足以收住情绪的变化 |
| 剧本看似热闹但成片平，或同一冲突拖了好几段 | [生成前的剧本压力测试](../../short-video-production/references/screenwriting.md#生成前的剧本压力测试) | 能指出哪次尝试改变了人物的下一步，以及哪条视听证据改变了观众判断 |
| 两人以上交锋、交接或换位 | [动作与局势变化](../../video-scene-direction/references/action-direction.md#高速动作与场面升级)、[人物走位](../../video-scene-direction/references/performance-and-blocking.md) | 起势有来路，回应有对象，结果改变双方距离、持物或通路。换位过程在画内，或者切前切后有同一动作或地标可接 |
| 连续跟拍、关键揭晓或多镜剪接 | [摄影与切镜](../../video-scene-direction/references/camera-and-cutting.md)、[镜头技法与应用](../../short-video-production/references/camera-and-editing.md) | 机位起点、触发、路径和落幅可以推导。切后出现新的可读信息，保留足以接续的动作、视线、构图或声场 |
| 异常光效、环境交互、局部破坏或大场面 | [特效、材质与环境响应](../../video-scene-direction/references/vfx-design.md)、[高密度特效分镜](../../video-scene-direction/references/cinematic-shot-plan.md#高密度动作与特效分镜) | 能看见效果来源和传播。局部损伤有边界，整体规模有参照。两个相近触发有可区分的响应，残留状态和下一镜的证明写进正文 |
| 舞蹈、齐舞变阵或冰上表演 | [舞蹈与冰上动作](../../video-scene-direction/references/dance-and-skating.md)，并按需读取[舞蹈表演层](../../video-scene-direction/references/dance-and-skating.md#面部表演手部编舞与头发二级运动)、[真人舞蹈表情](../../video-scene-direction/references/live-action-performance.md#舞蹈表演中的面部动作)和[头发二级运动](../../video-scene-direction/references/look-design.md#头发与服装的二级运动) | 除承重、脚底接触、路线和音乐短句外，还要核对表情节点、左右手手势路径、发束惯性是否写进实际镜头正文；换镜后动作和头发余势接得上 |
| 分辨半写实 3DCG、三渲二或真人，表情时画风漂移 | [画面美术与角色渲染](../../video-scene-direction/references/look-design.md) | 起幅定义渲染、光源及材质，开口、转侧脸、强光和切镜后仍维持原定造型与质感。可记住的画面有具体落点 |
| 真人表演、写真自拍、剧情对白或重要的听者反应 | [真人表演与写真质感](../../video-scene-direction/references/live-action-performance.md)、[对白时长](../../video-scene-direction/references/music-and-sound.md#对白时长与切镜) | 人物视线和表情由具体事件触发，在相应景别可见。光线和焦点保留可辨认的脸。说话人、对白原文、出声与沉默正确 |
| 动态写真里有局部互动、完整体态和对镜表情 | [动态写真与镜头互动](../../video-scene-direction/references/live-action-performance.md#动态写真与镜头互动) | 用户指定的主要看点占足时长，接触和反馈同框可读，手势、目光和有惯性的发束在实际镜头里有触发与收势；身体、服装与参考职责对得上 |
| 微表情读不出，或角色抢在反应前开口 | [H3 微表情的英文写法](../../video-scene-direction/references/live-action-performance.md#h3-微表情的英文写法) | 从成稿核对触发、具体部位、可见变化和开口或沉默的先后。眼与嘴在关键时刻可见。使用情绪锚定词时，把情绪幅度与动作顺序分开验收 |
| 声音负责冲击、提示或跨镜衔接 | [声音与卡拍](../../video-scene-direction/references/music-and-sound.md) | 能找出声音开始的接触或事件，知道哪层延续、哪层该退下。需要对帧时把准确落点交给时间线 |
| 固定台词、静默反应或样片乱说话 | [对白与静默控制](../../h3-visual-prompting/references/h3-formats.md#对白与静默控制) | 有原文、说话者和收口动作，声景提供明确的环境或拟音，静默段的表演与发声要求相容 |
| 招牌、屏幕、包装原字，或指定服装细节必须看清 | [画内文字与可读性](../../h3-visual-prompting/references/h3-formats.md#画内文字与可读性)、[主体外形写法](../../h3-visual-prompting/references/shot-enhancement.md#让主体外形在画面里可辨认) | 字样有原文、载体和读得出的取景。服装与配件有对应景别和实际可见时段 |
| 角色、动物、道具或场景必须稳定 | [主体外形和场景交互](../../h3-visual-prompting/references/shot-enhancement.md)、[H3 素材职责](../../h3-visual-prompting/references/h3-formats.md) | 角色或场景在镜头里有稳定称呼和可见识别点。各参考对应实际素材，只继承它负责的特征 |

按本镜职责取舍。静态镜头可用构图和表演，单人片段未必需要正反打。高密度需求按[场面复杂度](../../video-scene-direction/references/prompt-enhancement.md#根据场面复杂度增加细节)保留关键交互与节奏变化。

## 出稿前分别验收导演与模型

| 检查 | 可交付的标准 |
| --- | --- |
| 导演意图 | 能说清观众在开头、中段和结尾分别知道什么。动作镜头交代发起与后果，氛围镜头交代该观察的空间或情绪变化 |
| 画面选择 | 能指出机位移动或剪切露出了什么、形成什么对比、怎样改变注意力。主体、威胁和反应的位置有根据，关键信息处于景别覆盖范围 |
| 模型语言 | 把「坚定」「危机」「震撼」翻译成演员姿态、视线、道具、空间比例、声响或光影。关键事件写清主体做了什么、接触或触发点、随后变化的是谁 |
| 场景交互 | 必须出现的道具、环境响应和独立背景运动，在发生的镜头正文里有可见触发或起始条件、可辨认的运动和后续状态。小反馈另查接触点、变化区域、对比线索和可读停留。见 [H3 场景交互写法](../../h3-visual-prompting/references/shot-enhancement.md#把场景交互写进镜头正文)与[接触后的反馈](../../h3-visual-prompting/references/shot-enhancement.md#接触发生后还要拍出反馈) |
| 时空关系 | 相邻时间段顺序一致，人体朝向与摄影机路径有独立的空间参照，镜头能保住需要看清的手、脚和表情。复杂移动镜头按首帧、转折点、接触或揭晓帧和尾帧核对。环境变化与拟音有对应的触发动作 |
| 人物动态层 | 舞蹈镜头的视线与表情在指定拍点可辨；左右手有各自连续的动作路径和自然手指姿态；头发由明确的头颈动作触发，具有延迟、有限越位和回落，且没有遮住关键表情 |
| H3 输入 | 按实际模式核对正文语言、字段、镜头切点、环境声、配乐及真实素材槽。英文成稿与导演稿对照，检查转写有没有改掉动作顺序、方向、时长、原台词或画内文字。见 [H3 官方结构与本机输入](../../h3-visual-prompting/references/h3-formats.md) |

### 从成稿倒查镜头

1. 用[逐拍保留细节](../../video-scene-direction/references/prompt-enhancement.md#逐拍保留细节)依次对照导演稿、中文模型增强稿与英文终稿。单独读最终正文时，从画面和声响重建实际变化，检查首段、中段和末段能否逐项对上。若几拍因为主体在循环而被一并概括，检查其间是否遗漏机位、幅度、承重、过渡或环境变化。修回缺失的执行句，核对相邻拍后再交付。最后按需复核原台词和收口、画内原字、关键服装细节入画。
2. 分开核对人物路线与摄影机路径，随后检查它们在画面里能同时成立。镜内接触固定道具或把它用作近景视差参照时，按[固定道具与运镜视差](../../h3-visual-prompting/references/camera-control.md#固定道具与运镜视差)核对场景锚点、机位和接触范围。双脚是看点时，按[双脚入画与落点](../../video-scene-direction/references/performance-and-blocking.md#双脚入画与落点)核对迈步中途的取景与支撑。对每个真实切点按[硬切与过渡怎么选](../../video-scene-direction/references/camera-and-cutting.md#硬切与过渡怎么选)核对切法目的、前镜落幅、切换触发、后镜起幅。连续时空按[切点站位对齐](../../video-scene-direction/references/performance-and-blocking.md#在切点对齐人物站位)核对地标、落脚点、朝向、动作阶段和道具状态。确认使用了过渡时的画面或声音接点有写入正文。
3. 将每一关键变化的写法横向核对到摘要、保留分析、逐镜正文和声音。出现同一部件在一处只写局部变化、另一处暗示整体变化时，改成一致的部位、范围与结果。连续发生两个可能引起同类反应的动作时，查每个反应是否从正确的地点和可见触发开始。仅仅写出先后顺序容易让观众把后一个大反应归因于前一个动作，必要时将接触点、介质、传播方向或声音落点分开。素材切换或一镜多拍时另查资产名称、引用映射与可用时长。
4. 紧张节奏让动作、反应、机位揭晓或声音延续接替主导画面。镜头拥挤时优先让观众读清关键接触或结果，再加入能帮助阅读的动态层。按[让关键接触在画面里可见](../../video-scene-direction/references/performance-and-blocking.md#让关键接触在画面里可见)核对衣料、身体与前景会不会遮住触发点。凡是找不到对应正文、过程互相冲突或画框看不到的关键要求，修正后再交付。

内部核查可用短表或逐句复读。连续时空的切镜以及独立生成段的接点，按[逐项核对容易穿帮的状态](../../video-scene-direction/references/performance-and-blocking.md#逐项核对容易穿帮的状态)并排检查前镜落幅和后镜起幅。关键状态要从导演稿传入每段实际生效的模型正文，例如人物脚下的地标、移交时哪只手还握着道具、包挂在人物哪侧或道具离手后落在哪。若发现无因换位、换手、道具改挂点、场景状态重置或同一次接触重播，先改设计、切点或模型正文，再核对受影响的两镜。

分批生成时逐个核对表中的接点与两侧正文，同一触发只播一次，手、道具、视线、光和声音的变化都有来源。如果用首帧或首尾帧，确认素材已存在、槽位真实、图像内容和正文起终态相符。样片未生成时把要截取的画面写成准备条件。用户只要提示词时，将接点落在正文，必要的绑定或剪辑说明保持简短。格式检查验证字段和调度，成片遵循度需要样片。

### 从导演稿到模型正文

导演稿「让观众发现女人守的是避难者，并在浪落下后看到守护结果」。写给模型时，用空间与动作交代这层关系，例如「女人身后紧邻一道铁闸。栏杆间透出一盏暖黄色提灯，几双手抓着内侧栏杆。女人听见闸门响动，侧跨半步站到海浪与铁闸之间。浪从堤外侧落下。镜头继续横移，铁闸仍闭合，灯光仍亮着」。实际成稿还要写明可见的景别、机位路径和片段时长。多个重要状态塞进一镜时，先决定这一镜必须交代哪一个。

## 拿到样片后

需要评估事件顺序、可见交接、运镜与声音同步时，先用[逐事件验收表](event-validation.md)写出每项的证据，再比对样片的对应时间窗。

1. 核对版本。优先用用户提供的文件或工作流任务编号。通过文件名、实际画面、时长或有对应关系的提示词确认。同一文件名或时间接近只用于找候选片。
2. 先看片判断观众能否读懂目标，再检查关键动作和切点。记录「时间码、预期、观察、证据」。抽帧可核对构图、道具、首中尾和视差。实际连续播放或连续取帧核对切镜、动作节奏和闪变。对白、卡拍或拟音需要实际试听。只有部分证据时标明覆盖范围。
3. 把问题归到可改变的环节。生成结果按指令出现但观众仍看不懂，先改构图、表演或叙事安排。画面遗漏明确指令，先改可见线索、参考锚点或单段动作密度。画面正确但卡点偏差，先修剪辑或声音。证据不足以确定原因时，写成假设。
4. 给最关键的一处改动及回归条件。做 A/B 时记录同一工作流、模型与 LoRA、随机种子、分辨率、时长、参考输入、采样参数。改变工作流时，把它单独作为变量。先确认 B 改善目标，再检查 A 已通过的构图、动作或声音是否退化。没有 B 或设置无法确认时，保留「待复验」。

同一个必拍事件反复以同一方式失败时，以首次偏差为线索换一种控制手段。按最小改动选择重新写接触或触发、换已验收的首帧、用单独的运动参考验证，或把可剪开的部分拆段。保留已经通过的成片或镜头状态。重试次数按预算、偏差是否改变及下一次能否增加证据决定。

长镜头续接或多次重生成时，把采用的样片与镜号、实际时间范围及源接点帧对应起来。若换了前段版本，重新核对引用其尾帧、运动引导或音轨的后段，并检查新旧版本能否在原接点对齐。只在后段的实际依赖失效或关键证据退化时重做。普通硬切、独立锚点和未受影响的成片沿用已通过的版本。

### 核对提示词遵循度

- 按实际送入生成节点的正文列出检查项，分别核对主体可见特征、关键动作与因果、固定地标、机位和切点、末态及声音。每项记为符合、部分符合、遗漏或无法判断，并写可见或可听的证据及时间。正文没有指定的外观细节，可记录为下一次创作选择。
- 切镜先用逐段画面定位，再看预计切点前后的相邻帧，分别记录实际是否换机位、切点偏差和末镜是否揭示预期范围。只凭等间隔抽帧或自动场景检测时，对是否实际切镜保留判断。声音项经试听才判定。样片无法对应实际提示词、语言或参数时，按样片记录执行情况，保留版本差异待核实。
- 切点穿帮要找首个偏差帧，用一条可复查证据说明人物或道具在哪里、接触的是谁或哪个固定点、何时改变。前后景深、遮挡或取景变化使证据不足时标为无法判断。按首次偏差判断应改正文里的继承状态、实际输入帧还是后期切点，保留已经通过的镜头。
- 对多余对白，全段试听并标出台词前后是否还有人声；同时看嘴是否跟着动。对指定文字，逐字核对在可读帧上的字形、次序和跨帧稳定。用户确认修好时，可记录该修订组合得到确认。若同时修改了标签、口型、声景或取景，逐项归因需用可比样片验证。

| 当前证据 | 反馈可写到哪里 |
| --- | --- |
| 只有提示词 | 指出文字设计哪里可能失效，给下一轮需要观察的证据 |
| 已确认对应的样片 | 写实际时间码和可见或可听的问题，再给一个可执行改动 |
| 可比的 A/B 样片 | 就相同时间段报告改善、持平或退化，决定保留哪一版 |

### 比较一句话增强的收益

- A 是原始简述按 H3 格式封装的基线，B 是同一简述按技能拍法增强的版本。两版必须使用相同 H3 工作流、生成模式、参数与配对种子。用 1160 穿透模式放入两份已格式化的正文，避免再次改写。C 可用同一句简述、时长、画幅和参考素材生成的即梦原片，供比较最终观感。
- 事先确定评分项。原意与必要事件须通过，再对画面看点、运镜叙事、动作与环境因果、节奏与声画和场景连贯逐项判断。每项可用 0（缺失或明显错误）、1（能辨认）、2（清楚且有效），结合时间码记录证据。题材没有相关设计的项可在生成前统一换掉或标为不适用。
- 需要报告相对目标时，若即梦比分高于 H3 基线，用 `(B − A) / (C − A)` 表示本机增强缩小了多少成片差距。多个题材用同一规则，并保持每组设置一致，报告原始分数、样本数和变动。A/B 用来归因 H3 提示词，C 用来观察整套平台的输出差异。缺少可比样片、原意失败或 C 未高于 A 时，保留原始观察与分数。
- 相对分数用于追踪差距。目标是尽可能接近参考成片，后续优先处理能定位且影响最大的差距。复杂任务单独核对多主体衔接、空间转换和层叠环境响应，避免总分掩盖关键动作遗漏。要比较细节密度时，在 H3 上固定故事、镜头与设置，对照简述与展开写法。保留能改善成片的细节。
- 审查参考成片时先写最希望接近的两项可观察表现，再从时间段定位差距。即梦对照用来衡量整体画面和声音观感。文字审查可确认预期是否写清，实际观感与差距以可比视频为依据。用户只优化技能时保存方法即可。
- **比较两套提示词增强规则时，先对照写词结果。** 固定原始创意、素材职责、时长、画幅、锁定对白和写词模型。分别保存两版增强规则和最终实际送进 1160 的完整正文。用同一组必保事件和格式检查找转写漏项，再用合格候选进行本机样片对照。若要比较写词模型，改用同一套增强规则和相同输入。单个候选失败时保留其原始输出或错误状态，方便区分可修的提示词问题和执行异常。
- **沉淀已复验的常用写法。** 在既有研究记录里保存要解决的现象、可替换输入、必须继承的状态、采用版本及原始样片或证据位置。用于新场景时重新填写人物、地标、动作、时长和实际素材槽，按当前环境复核可见性与生成模式。先在另一场同类任务复验，再将该写法作为通用方法。
