# 音乐与音效指导

给全片确定一条声音时间线。先写听者此刻要听清什么、哪个声音推动动作、哪一处希望突然安静。每个段落只标最重要的声音落点。

## 安排声音层

| 声音层 | 写到什么程度 | 交给生成还是后期 |
| --- | --- | --- |
| 对白、口播、画外音 | 谁说、语速、停顿、是否在画内、接收者何时反应 | 口型是镜头关键时随镜头一起验证。跨镜对白或准确语气可独立录制，再依时间线铺放 |
| 环境底声 | 地点、远近、持续时间、跨镜是否延续，例如池水与树叶从头到尾维持 | 生成声景可作草稿。逐段合成时可用同一条底声把接缝铺平 |
| 动作音效与拟音 | 声音由什么触发，何时开始、强弱、尾音多久。例如落脚、布料摆过、道具碰到桌面 | 需要同步的声音跟画面的可见接触点走。精确的脚步、碰撞和重拍优先在剪辑中对帧 |
| 音乐 | 节拍速度、重拍、音色、音乐何时进出、重音落在哪 | 舞蹈或卡剪先定一条全片音乐。逐段生成时可分别保存环境和动作音，统一在时间线配乐 |
| 留白 | 要压低哪一层、保留哪一层、多久恢复 | 可用削弱配乐突出一次落脚或反应。以最后试听效果为准 |

## 高能舞蹈配乐与动作卡拍

K-pop 女团 MV、Twerk 或高强度舞蹈片的配乐要提供明确的动力和层次。先确定音乐是实际输入的参考音频，还是仅用文字描述的原创配乐；只有分析过实际音轨或用户明确指定时才填写精确 BPM、拍点和时间码。

- **音乐质感。** 可组合强劲底鼓、厚实 sub-bass、清晰军鼓或拍手、密集 hi-hat、短促电子合成器音色、上升音效和低频 Drop。开场尽快进入节奏，中段增加鼓组或合成器层次，高潮让低频和打击乐同时增强，片尾用明确重音收束。用户要求激烈时，优先提高鼓点冲击、低频力度和节奏密度，而不是单纯把速度写成极快。
- **把声音映射到动作。** 底鼓可对应屈膝下沉、回弹或重心落点；军鼓/拍手可对应髋部隔离、手臂击点或定形；hi-hat 支撑细小连续律动；鼓组填充可触发脚步变化、转身或身体 Wave；Drop 对应动作强度最高的一组编舞；最后一个重音对应收势。不要把每个鼓点都配成独立的大动作。
- **安排音乐短句。** 用 4 拍或 8 拍组织起势、重复、变化和收尾。动作可在重拍前轻微蓄力，在重拍上完成落点；切镜点可以与重拍一致，也可以略微错开以保留动作过程。若没有实际音轨，只写“开场强拍”“中段鼓组填充”“高潮 Drop”等相对位置，不捏造精确秒数或 BPM。
- **区分声音字段。** 整段持续的音乐写入 H3 的 non_diegetic_music；房间底噪、鞋跟接触地板、衣料摩擦等写入 overall_soundscape；由某个具体动作触发、必须在某镜同步的声音写入该镜正文。音乐由后期统一铺设时，按实际工作流避免重复生成另一条音乐。
- **保留舞蹈可听性。** 音乐应是主导层，脚步声只在重要落脚或转身处清楚出现，不要盖过鼓点。若需要精确卡拍，最终以实际音轨波形和剪辑时间线校准，生成模型的文字指令只负责引导节奏。

## 对白时长与切镜

先逐句记录说话人、原文、出声方式、句前动作、必要停顿和听者反应。有录音时量实际语音和原有停顿。有条件时按角色语气试读计时。两者都没有时，用中文口语可发音字数÷语速估算。数字、字母和缩写按实际念法换算，标点用来安排停顿，原台词照存。

以下速率只用于无音频排期，单位为字/秒。语义、角色、方言和表演都会影响实际时长。

| 语气 | 估计速率 |
| --- | --- |
| 平静陈述 | 约 4 |
| 轻松调侃 | 约 4.5 |
| 激动或争执 | 约 5–5.5 |
| 低沉或犹豫 | 约 3–3.5 |
| 郑重宣告 | 约 3.5 |
| 急促催问 | 约 5.5–6 |

- 镜头占时按朗读时间加实际需要且不与朗读重叠的呼吸、动作和反应计算。需要时可先预留约 1–2 秒再试读，与同拍动作重叠的部分只算一次。
- 先判断动作和台词是否能在同一镜头内读清。双人同框可保住递物、对望和同时反应。脸或口型反复串位时可测试单一可见说话者、过肩或反应镜头，核对视线、画外声和听者状态。每句对白可与前后句共处同一镜头。
- 长台词跨镜时在自然语义或换气处处理，也可保持一条连续录音，用反应或道具插镜承载画外声。跨生成段记录原文起止和接续，拼接后逐字对照。用户锁定的对白、语言和说话人保持原样。总时长与原速对白冲突且无法靠重叠或剪辑解决时，指出超出的时间并请用户决定可调的约束。
- 分镜表内部保留估时。H3 单镜内用触发和动作先后描述台词何时开始。真实切镜才使用该模式的切镜标记，并让声音沿指定的接点延续。画内说话交代说话者的自然口型与语气，旁白不驱动画内人物口型。单段上限看当前工作流选项。

## 卡拍和跨镜

- **先定拍点，后写切点。** 从既有音乐的实际波形、拍点或重音位置取标记。若为原创节拍，按每分钟拍数 BPM 计算拍距（秒）为 60 ÷ BPM。例如 100 BPM 的拍距是 0.6 秒，第一拍在第 0 秒时，第 3.0 和 7.2 秒都落在节拍线上。实际重拍取决于节奏型，单独写清。
- 区分**踩鼓动作、剪切点、同步音效**。三者可落在同一拍，也可让一个动作提前蓄力，在接触帧播放音效。模型生成的重音时机按出片检查，精确对齐使用剪辑时间线。
- 声音需要牵引视线时，先听到下一场的声音再切画面（J 切）。想保留前一场情绪时，让上一场声音延续到后一个镜头（L 切）。回看时关一次配乐，确认对白清楚、同步音合理，再打开配乐检查动态和层次。 [Premiere J 切与 L 切](https://helpx.adobe.com/premiere/desktop/edit-projects/trim-clips/perform-j-cuts-and-l-cuts.html)
- H3 写法中，某一镜触发的声响和对白写进镜头，整段底声与拟音概述放在 `overall_soundscape`，观众听到的配乐放在 `non_diegetic_music`。若配乐由后期统一铺设，该字段可用 `N/A`。 [ComfyUI MiniMax H3 提示词指南](https://docs.comfy.org/tutorials/video/minimax/minimax-h3-prompt-guide)
