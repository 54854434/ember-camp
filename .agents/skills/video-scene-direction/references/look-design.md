# 画面美术与角色渲染

依据题材、用户指定和真实参考选择渲染方式。先明确角色身份、服装和妆容，再决定表面着色、场景光源、调色和摄影。参考只提供运镜或节奏时，原定角色媒介照用。选中的画面特征写进全局基准，侧脸、台词、强表情、极端机位和效果强光等风险镜头再具体说明需要保住的特征。

| 视觉方向 | 在提示词里写出什么 | 重点复核 |
| --- | --- | --- |
| 半写实 3DCG（stylized character CG） | 可辨认的三维骨点和发束大形，皮肤受光有柔和体积、局部高光和粗糙度差别。金属有方向性的亮边，织物有弯曲与遮蔽，皮革较挺 | 转头、开口时脸和口周仍由同一角色造型产生。面颊底色、妆容和灯光染色分开写。表情幅度按剧情允许扩大，保持眼睑与目光、唇颌和牙列协调 |
| 游戏式三渲二（3D cel shading） | 环绕和仰俯视中有清楚的三维体积、穿插和视差。脸用干净的二分明暗与柔和色阶，肤面简洁。发束有体积和条带高光，按需要写细描线、轮廓光及服装材质差别 | 口型、形体和发束仍属于同一模型。分清镜头外观与真实透视，避免画成跟镜头同向旋转的平面立绘。特效也沿用相容的边缘、色块和光影 |
| 真人电影（live-action cinematography） | 用窗、灯或环境反射塑形，保留符合年龄的皮肤纹理、面颊和鼻唇过渡，眼睛反光有来源。近景按动作写目光、自然眨眼、呼吸或唇颌联动 | 脸转离主光时阴影随实际方位变化。保留原有年龄感与妆容。柔光、胶片颗粒和高光滚降按需要选用，让关键眼神和接触仍可辨认 |

风格名称、作品名和拍摄器材可作沟通线索。入词时把「某种光感」具体化为主光位置、软硬、色温、明暗比例、前后景分离与高光过渡。用户指定高饱和、深阴影、极端机位或强光时保留意图，用亮度、轮廓和运动的先后让重要信息可读。

头发从固定的发根及主发束开始。转头或遇风时，发根随动，松散的发梢稍后跟上，急停后有一次有限越位并逐渐回落。服装从肩、腰或扣件受力，游离的衣摆和袖口稍后传递动作。薄料轻快，厚料有大褶且收势较迟，硬甲大致保持形体。头发与肩、领口、道具接触时写清遮挡或顺着表面滑过。跨镜保留发梢、衣摆和残留动势的阶段。

## 用画面判断美术安排

| 检查 | 成稿中的可见依据 |
| --- | --- |
| 叙事意图 | 观众先看懂什么，哪一个可见变化让观众改变态度或理解 |
| 视觉主次 | 当前重点的轮廓、面积、深度、明暗或动作有优势；人物之间的关系能看清 |
| 光色与材质 | 主光和空间有关系，材质各自响应，强调色集中在需要注意的地方 |
| 节奏 | 关键变化有足够画面停留；极快、极慢、留白和声音都服务于当前动作 |
| 可记住的画面 | 利用已有角色、物件或空间设计一个具体且符合题材的结果 |
| 取舍 | 每一层运镜、反应、颗粒或拟音有用；同类视觉峰值可让位或错开，有用的呼应可以保留 |

有样片时按首次偏差定位。过曝遮挡轮廓就调整亮度分配或出现顺序；材质趋同就补具体表面的反射方式；脸在开口后改变就对照发音前后的同一造型和底色。只有设计稿时记录风险和可复核证据，实际结果按[成稿审查与样片反馈](../../short-video-supervisor/references/review-loop.md)结论。
