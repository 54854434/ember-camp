# 电影镜头设计与提示词交付

用于用户给出详细提示词作为写法参考，或镜头涉及多段走位、空间揭示、连续运镜、道具交互与声画同步的任务。先明确这条镜头希望观众看到的变化，再决定细节量。保留从参考中提取的做法，人物、情节和资产按用户本次要求确定。

## 导演稿的六部分

| 部分 | 写到可执行的程度 |
| --- | --- |
| 画面质量 | 选对关键画面有帮助的介质、光学和纹理。例如何处需要浅景深，哪两个对象需要同时清楚，窗光怎样照出皮肤或湿布质感。相互冲突的焦点和清晰度先处理 |
| 风格与氛围 | 用色温、主光来源、明暗关系、材质与节奏落实风格。给环境建立统一色调，将色彩或音量的变化留给剧情转折 |
| 第一帧画面描述 | 定画幅、景别、机位高度和朝向，写主体在画面哪一侧、处于什么姿势、道具当前状态，以及观众此刻该看到的地标。图生视频从真实输入帧接动作。纯文本按描述建立首帧 |
| 场景元素 | 按主体可走通的顺序布置区域、入口、出口、固定地标和可动道具。说明同一物件的初始位置、持有者、发生变化的原因及变化后的去向。分别标明会随动作变化的环境与作为空间参照的静止物 |
| 运镜轨迹 | 依次写开场机位、跟随对象、经过的地标、转向或升降原因、露出的新信息与结束构图。持续运动时，每一拍让上一拍的末态成为下一拍的起点。需要看清反应或接触时，先保证景别和遮挡关系 |
| 音乐音效 | 区分持续的环境底声、由动作触发的拟音和画外配乐。标出关键声音的开始、强弱、远近和收尾。如果声画同时结束很重要，先写成同一事件，再在后期时间线上精确对齐 |

## 连续轨迹与切镜

- 用「触发事件 → 主体动作和物件变化 → 摄影机跟到哪里 → 观众此刻看到或听到什么」组织每一拍。按需求保留转向、下降、跟拍和收势等阶段。为转折写一个真实的空间节点，例如门框、走廊转角或桌沿。核对摄影机能够沿路线越过这些位置。
- 用 A、B、C 标记空间时，先检查区域相邻关系和人物朝向。它们可以全部属于一个连续镜头。发生硬切或其他实际转场时，再新增镜号并写切点。切镜前后应有可读的视线、动作接点或构图匹配。
- 区分叙事因果、背景反应与摄影机动作。人物伸手、道具发生变化、另一人反应有先后时，写出可观察的接触前、中、后状态。多个变化必须同拍时，只突出本拍最值得看的变化，其他元素服务于它。
- 四步 Turbo 优先保住开场、关键接触或揭示、尾帧这几个可验收的画面。预期负荷过高时按真实反应、遮挡或落脚点处理。用户明确要一镜到底时，先减同拍动作或测试关键段。能接受多段时再拆段剪辑，明确成片切点。

写法示例只用于说明同一镜头里的三个空间节点。镜头起在书店门外的玻璃上，店员拉门时沿门框进入，近处门框滑得比远处书架快。门铃响过后，机位继续跟到柜台一角，才露出桌上的信封。结尾轻轻收近，店员手停在信封旁，窗外雨声继续。门口、进店和柜台共用一条路径与连续的声场。

## 高密度动作与特效分镜

用于需要快速交锋、多镜动作衔接或大范围特效的场面。导演设计可先定全片的角色识别特征、固定地标、光线、主特效颜色和材质，再逐镜组织机位、动作、冲击与环境响应。角色与特效靠轮廓、颜色或运动特征区分。画质用观众能看见的材质、光影和构图表达。渲染器、编码、输出像素和帧率按真实工作流设置。

- **先排运动的起势、发展与收势。** 开场让观众看见主体从哪来、朝哪走。中段保留能读出的运动方向，并在一两个值得细看的动作上让节奏短暂放宽。收势时可以拉开景别，交代主体停在哪里、影响扩散到哪里。三段是动作节奏，同一镜可以走完这三个阶段。发生剪切再增加镜号。
- **给观众一个可以接着看的对象。** 机位或景别快速变化时，用手中道具、一道运动轨迹或一个醒目的姿态承接视线。交代它在切前从哪侧移动、切后先在哪一侧出现，并保留足够的人物或环境信息。视线需要从动作转向结果时，让原来的轨迹引到受影响的位置，再用更宽的构图交代全貌。
- **把特效写成过程。** 指定特效从哪个动作或接触点出现，形状与颜色如何辨认，朝哪里传播，遇到什么后改变，以及末尾如何消散或留下痕迹。需要分层时，区分核心、边缘与残留的职责。余光、烟尘、水面和碎屑按距离与触发先后响应，并留出能看清人物和接触点的区域。
- **给效果一个稳定来源。** 用角色、衣袖、虚构道具或固定空间处作为发光起点。需要半空残影时区分随主体移动的光、留在旧轨迹的光和留在场景里的痕迹。双方可用不同轮廓与颜色识别，切镜后继承相同的来源、特征和剩余状态。场面要显得大时，可先拍近处一个清楚的反馈，再用地标或较远处的延迟响应显示传播范围。
- **把随身运动和环境响应写出时差。** 衣摆、发梢和道具拖尾跟随主体惯性。背景中的轻质材料、烟雾或水面在扰动抵达后改变方向或形态，主体收势后可以继续回落、漂散或回稳。让其中一个最清楚的响应承担镜尾结果，其余细节按景别取舍。
- **让局部反应和远处规模先后被看见。** 同一触发可以先带出可读的近处接触，再沿地面、水面或空气向远处呈现逐层响应。用中景确认谁触发、什么变化，再用开阔的构图看清扩散及位置关系。重复轻碰撞可用短促声音和小幅局部反馈，峰值给一个更强而清晰的可见结果。让焦点和取景优先保证关键人物、接触点及后续交锋读得清。
- **给冲击留出强弱。** 普通交锋可用局部火星、短促声音或轻微位移。重要交锋可增加材质形变、环境位移或一拍速度反差。高潮可扩大影响范围，先拍清接触，再展示冲击传播到远处和环境余波。按写实、风格化或奇幻程度选择效果。全屏闪帧、定格和强震动只在能强调叙事节点时增加。
- **一镜先定一条主运镜。** 根据这一镜要看见的位置、速度、接触或结果选主路径。复合运镜沿同一路径衔接或按触发点分阶段，先交代机位怎样移动，再说明景别或焦距带来什么可见变化。变焦、实推拉、摄影机变速和剪辑变速分别用可见结果描述。精确的变速曲线、定格与闪帧在后期按帧实现。 [Adobe Premiere 变速指南](https://helpx.adobe.com/premiere/desktop/edit-projects/change-clip-speed/different-ways-to-change-clip-speed-and-duration.html)
- **把遮挡当成有起止的切点。** 切前写清哪个已有的近景物体、水幕或烟尘从哪侧掠过，以及何时盖住画面。切后从相容的遮挡方向、动作阶段和声场接回，遮挡退开后交代新的景别或视角，并保留地标与现场状态。需要视觉上连续的多段生成时，可在后期对齐遮挡覆盖最完整的帧。

将上述安排写成目标模型看得见、听得见的事件。短段优先保证动作链、一个关键冲击和可辨认的结果。保留用户给定的关键事件，再按时长取舍动作数量和特效层数。实际需要剪切才新增镜号。做多段时按各段可用时长排镜，并给上一段尾帧与下一段首帧留可辨认的衔接状态。

## 从公开案例提取的方法

- **@aiehon_aya 的开箱 ASMR** 把面部反应和精细的手部操作分给不同画面，每个关键动作有胶带、纸板或包装纸等可辨认的近处声音。迁移时给关键接触和人物反应安排各自看得清的画面。若需要连续镜头，可沿轨迹先读接触，再揭示反应。 [提示词原文与成片记录](https://awesome-minimax-h3-cases.zzskysilent.com/cases/x-2082768164413428159/)
- **AI 代码侠土豆的双人文戏** 把听者的停顿、垂眼和接话分给不同动作拍。迁移时用原台词中的触发词，给听者一个可见反应和过渡时机。本机正文用已支持的语法表达台词和表演。 [作者中文示范](https://github.com/AICoderTudou/tudou-single-h3#06--完整示例一句追问一次迟来的回答)
- **鳌拜拜的循环讲解** 把手势、面板出现和声效写在同一个事件里，角色图与音色各有不同职责，结尾恢复开场姿势。迁移时按实际素材分工，并明确静音、动作音和配乐的边界。 [作者完整六字段案例](https://github.com/3ALLBUY14/h3-prompt-builder/blob/main/references/prompt-examples.md#L31-L65)
- **@umesh_ai 的悬崖城市追车** 让摄影机先定位主体、中段表现相对速度、结尾揭示环境规模。迁移时给每段运动一个视觉目的。 [提示词与成片记录](https://github.com/ZeroLu/awesome-minimax-h3#speeder-chase-across-a-cliff-city)
- **@aiwithaly 的街拍和 @amynys 的落叶喜剧** 分别用相机里的照片和散开落叶后露出的泳池给动作提供结果。迁移时明确画面中什么先被遮住，哪一步触发揭晓，最后给结果留足可读时间。 [街拍提示词与成片记录](https://github.com/ZeroLu/awesome-minimax-h3#street-photographer-candid-moment) · [落叶喜剧原文与成片记录](https://awesome-minimax-h3-cases.zzskysilent.com/cases/x-2102443755240407287/)
- **@aimikoda 的节拍角色展示** 让角色图负责身份，音轨负责剪辑节奏，镜头与环境承担主要变化。迁移时把音乐重音分给动作或剪辑，先在短段检查一处重音和换景的关系。 [提示词与成片记录](https://github.com/ZeroLu/awesome-minimax-h3#beat-synced-character-showcase)

上述方法来自已公开的文字或样片记录。固定机位、镜头数量、精确秒数和专用标签只在当前内容及入口需要时采用。借鉴 AIX 爱客的提示词对照和 Pip 的固定种子记录时，复用可比条件。测试提示词时固定工作流、素材和种子，仅改一个可定位的问题。比较采样或分辨率时保留原提示词。优先对照原始输出，单独记录后处理。 [AIX 爱客提示词对照](https://www.bilibili.com/video/BV13a4Z6DEur/) · [Pip 的六组本地对照](https://www.bilibili.com/video/BV1ajpm6jEjP/)

## 编写 H3 与 1160 交付

空间路线难以仅凭文字验收时，先画开场、关键转弯和结束位置的简图。核对主体、相机、障碍和光线能否连续，再依实际目标决定是只审草图、接入首尾帧，还是准备短运动参考。见[镜头预演与逐事件验收](../../short-video-supervisor/references/event-validation.md)。

1. 上面的画质、氛围、首帧、场景元素、运镜和声音用来构思镜头。转成模型正文时，先讲观众看到的开场构图，再沿同一条时间线写主体动作、摄影机如何回应、现场反馈和落幅。Ref2VA 把全段共有的画风放在首镜之前，镜头动作与声画同步留在 `detailed_description`。整体声景概述放入 `overall_soundscape`，画外音乐放入 `non_diegetic_music`。
2. 纯文字用 T2VA 三字段，绑定实际参考时按具体模式写。Ref2VA 的六字段承载素材角色、保留关系、镜头与声景。用户本机的成稿默认用完整 1160 中文分段，模型字段名和调度标记保留原样。详见[H3 官方结构与本机输入](../../h3-visual-prompting/references/h3-formats.md)。
3. 交付前从开场走到尾帧，核对人员、机位与道具是否接得上，声音是否有触发，每次运动是否让重要信息更好辨认。检查参考标签是否在实际起作用的地方出现，尤其是背景动作、服装继承和切镜。默认把导演设计写进可粘贴成稿。审片按[时间码反馈流程](../../short-video-supervisor/references/review-loop.md)记录期待与实际差异。
