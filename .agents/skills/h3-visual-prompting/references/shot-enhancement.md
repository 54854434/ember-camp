# 镜头设计与提示词增强

## 四步 Turbo 的改写顺序

1. **先锁住用户的意图。** 把角色身份、原对白、关键道具、时代与空间关系、时长、目标景别、画风和不能改变的结局记下来。用户只让背景动时保留主动作、景别、切点和口型。
2. **先建立可见的静态条件，再推进动作。** 镜头开头写相机在哪、角色在哪、重要物品在哪、谁遮挡谁、光从哪里来。随后按起始状态、触发、变化、结果排动作。细节有画面或声音的证据。一次性给四步模型太多竞争动作时，优先保障本镜叙事动作，把其他动作变为弱背景、拆到下一镜或分段生成。
3. **从局部增强开始。** 只润色画面或运动时先改 `detailed_description`，新增声响并需要输出时同步整体声景。确实新增、移除或重编号引用时才同步修改定义、摘要、保留分析与调度。若要求保持原配乐和对白，沿用原文。
4. **按证据升级。** 保持种子、参考图及其顺序、长度、分辨率、采样器、步数与 LoRA 一致，先对照提示词。对关键信息仍不稳的镜头，再单独测试更清晰的参考、固定机位或更短的段。原生 R2V 的基础采样与四步 Turbo 是两套工作设置；对照基础模型时按官方原生分支使用匹配权重和采样设定。 [ComfyUI 原生 Turbo 与参考说明](https://docs.comfy.org/tutorials/video/minimax/minimax-h3-native)

官方 Ref2VA 指南鼓励生成任务细写可见可听的信息，给出通常 350–500 英文词的参考范围。当前四步分支用实测来决定细节密度。短镜头保留有效的动作链，复杂镜头可写足各层次，再根据生成结果删去争抢注意力的细节。 [MiniMax 全参考详细描述规则](https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/docs/VIDEO_PROMPT_WRITING_GUIDE_ref_en.md)

## 让背景物体真的运动

给背景物体写清：

| 要素 | 提示词要回答 |
| --- | --- |
| 物体与位置 | 屏幕里哪里能看见，大小是否足够辨认，主体挡不挡 |
| 初始状态 | 朝向、开合、形状、接触面或固定支点 |
| 触发 | 风从哪里来、谁碰了它、机械什么时候启动 |
| 运动 | 哪一部分朝哪里动，速度、幅度、次数或持续时间 |
| 结束 | 停在哪里、是否回弹、运动过后什么保持原位 |
| 影像与声音 | 镜头怎样看见这次变化，是否需要对应的声响 |

避免把关键运动藏在深虚焦、画面边缘或快速大幅运镜里。先用固定中近景试一次，确认是物体自身在动，随后再决定加运镜或虚焦。需要明确让空间活起来时，主动作和背景叠加可用同一触发点，其他布景保持稳定。

**你的小白兔镜头可这样做单变量对照。** A 沿用原提示词和原素材。B 只在 `[Shot 1]` 的「约第3秒，它用两只前爪缓慢拿起胡萝卜」后接下句。窗帘要在此镜可见。如果原参考已经裁掉窗帘，先固定一份包含窗帘的画面，再用同一份参考跑 A 和 B。

```text
窗在画面左后方半开，窗帘下摆在兔子耳朵左上方清晰可辨。兔子抬起胡萝卜时，窗外一阵轻风将下摆向室内吹起一次；上缘固定在帘杆上，下摆回落后逐渐停住。木桌、白瓷盘和机位保持稳定。
```

第一轮只比能否看见「下摆抬起 → 回落」以及兔子是否仍完整完成拿起、轻咬、抬眼。窗帘声音留到单独一轮测试。若主体动作被抢走，减小扬起幅度或错开到兔子拿稳之后；若没动，先提高帘边在画面中的可见度。记录实际生成效果，再决定采用更详细提示词、拆镜或用明确的动作参考。

## 从审片结果选择下一次测试

分别看**身份与构图、动作完成度、动作顺序、时间连续性**。脸和背景稳定的镜头仍需检查指定动作是否发生。按「起始状态 → 关键动作 → 结束状态」各看一帧或一小段，再完整顺放检查过渡、速度和音画同步。需要决定整季工作流时，在可用预算内用另一组固定种子重复同样对照，记录每个镜头的通过项和失败项。 [VBench 对视觉一致性与动态的独立评估](https://arxiv.org/abs/2311.17982)

- **身份漂移或细节糊。** 检查当前参考分辨率和目标特征在参考图中的占比。本地 1160 的低内存参考路径会按参考图数量限制单张图的缩放预算。近景优先试裁出的角色面部或道具细节，并保留用于身体比例或环境布局的必要参考。
- **动作完整但落点或时机失准。** 当镜头有明确的中间或最后姿态时，可以在有相应节点的原生 H3 工作流中试 `MiniMaxH3AddGuide`，指定目标帧的姿态、短片段或声音。确认实际帧号和接线。普通 Ref2VA 身份参考仍按其本来用途写。 [ComfyUI 原生 H3 导引节点](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/MiniMaxH3AddGuide/en.md)
- **画面动作没错，情绪或信息落点仍弱。** 先从[导演分镜与审片](../../short-video-production/references/directing.md)复核观众跟谁、什么时候看见证据、需要几拍反应，再决定是否改生成 prompt。

## 用运镜、切镜表达感情

先写观众此刻要看见什么、何时意识到它，再选镜头语言。推进是摄影机实际靠近，变焦是焦距变化；摇镜转动机位的朝向，横移让机位在空间平移。运镜写进动作句，写清方向、幅度、速度、结束构图和触发时机。

| 叙事需要 | 可选镜头 | 要拍到的证据 |
| --- | --- | --- |
| 悬疑、信息慢慢露出 | 门框遮挡中的固定镜头，或小幅慢横移揭示；切细节只在出现新线索时 | 角色先停住，横移后观众才看见门把自行下沉 |
| 紧张、倒计时 | 从角色到计时物的一次硬切，再给选择或结果；跟拍时尽量稳定轴线 | 秒数、手指停顿、最终按下或收回 |
| 亲密、犹豫、失落 | 稳定的中近景、轻推或在反应上停留；镜头靠细小表演推进 | 眼神移开、肩膀下沉、手慢慢松开 |
| 喜剧 | 固定双人中景保留表演和停顿，包袱后的反应切镜或道具插镜 | 前后两人的反应差，或一件道具突然改变预期 |
| 压迫、空间不安 | 利用近处遮挡、偏置构图和画面边缘；轻微手持用于视角不稳 | 通道收窄、人物退到边缘、视线反复回到同一处 |
| 释然、孤独、建立规模 | 拉远或切远景，选择什么时候让观众看见人物与空间的关系 | 手放松后空间打开，或人物变小而环境继续运作 |

切镜带来新主体、新视角、新位置、状态或时间信息。对话反打留意视线方向和过肩位置，动作匹配可在同一动作中切到近景；涉及道具状态时，切前和切后核对手、位移及物体朝向。切法、音桥和表演的作用跟每场戏的叙事目的走。 [MiniMax 基础模式镜头规则](https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/docs/VIDEO_PROMPT_WRITING_GUIDE_base_en.md)
