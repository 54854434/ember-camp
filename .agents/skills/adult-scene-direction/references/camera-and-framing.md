# 成人向镜头与构图（整合 xingheFF + WeissGoat 实测）

## 1. 默认相机声明（明确内容优先）
```
The camera holds a static shot; the frame never moves: no cut, no pan, no tilt, no zoom, no push-in, no camera shake and no reframing.
```
静态比任何运动更能保住解剖细节与接触点。只有用户明确要求运动时才加入一次运动。

## 2. 景别（Shot Size）推荐

| 景别 | 推荐英文 | NSFW 用途 |
|------|----------|-----------|
| Full / Long | full shot, long shot | 全身站姿、后入全景 |
| Medium | medium shot, mid shot, knee shot | 最通用：动作 + 脸 |
| Medium close-up | medium close-up | 脸 + 上身 + 插入（推荐默认，脸必须可读时） |
| Close-up | close-up | 表情 / 口交 / 局部接触 |
| Extreme close-up | extreme close-up | 生殖器细节、液体、眼睛、嘴唇 |

规则：女主角为主时优先 medium 或 medium close-up。

## 3. 视角（Camera Angle）

### 垂直
- eye-level / eye level shot（默认最自然）
- high angle / from above（脆弱感、清晰看到插入）
- low angle / from below（支配感，用户要求时用）
- overhead / top-down（特殊构图）

### 水平
- front view / straight on
- side view / profile
- back view / from behind
- three-quarter view / 3/4 view
- over the shoulder (OTS)

### 常见体位推荐组合
- Missionary POV：high angle 或 overhead + medium close-up
- Doggy（第三人称）：side view 或 three-quarter from behind + medium shot
- Cowgirl：front view 或 slight high angle + medium shot
- Standing：side view 或 three-quarter + full / medium shot
- 第一人称揉胸/下探：static first-person POV，双手从画面下方进入

## 4. 灯光（默认推荐）
- Quality：soft light / diffused light
- Direction：Top-Left Soft Key（默认）或 soft window light from left
- Color：warm soft key light
- Intensity：soft ambient，minimal harsh shadows

## 5. 提示词顺序建议
[Angle] → [Shot size] → [Subject & action] → [Lighting] → [Quality]

示例：
medium close-up, eye-level, static first-person POV, the viewer's hands kneading her breasts..., Top-Left Soft Key, soft warm light

## 6. 第一人称特殊规则
- 双手必须从画面下边缘或侧边自然进入并始终可见。
- 贴身时写：`her breasts nearly fill the frame`。
- 反复确认：`The viewer's hands remain clearly visible in the frame.`
- 避免双手突然消失或穿模。

## 7. 运动限制
一次镜头只允许一种运动，且幅度小、速度慢：
```
The camera slowly pushes in with small amplitude toward the point of contact.
```
明确内容默认完全静态。
