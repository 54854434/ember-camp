# 特效、材质与环境响应

适用于电影、动画与奇幻画面。先决定主效果在叙事里做什么，再写它从哪里出现、沿什么介质或设定的路径运动、和谁接触、在什么条件下结束。用门洞、柱距、岸线或人物身高给规模参照。次级形体说明受力或流向，小细节集中在接触区与边界，背景效果保持时间、风向和空间一致。

## 从起因写到余波

1. 先明确发生前的基线和源点，例如水面已有细纹、承重石柱完整、帘脚只有风吹的轻摆。对可能混淆的两种触发，分别写地点、接触、响应幅度、传播方向与声音。例如水面的先动可沿经过水面的效果路径起纹，另一次实际入水的碎块只在它的落点起局部波纹。按实际叙事分配主次。
2. 写可见的主形、方向、范围和变化过程。效果有蓄积或停留才写，允许突然开始。用视差、遮挡、厚薄和附近表面的反光证明它处在场景里。高亮能短暂占据画面时，给观众时间看清它的来源和后果。
3. 写实际留下的结果。已离开源点的碎屑、雾、尾迹和波前可以继续。接镜记录仍在移动的部分和永久改变的部分，必要时给后镜保留一个见证地标或近景。把声响系在实际碰触、脆裂或回落处，远处保留相应的空间尾音。

## 按效果选择写法

| 类别 | 给出的可见依据 |
| --- | --- |
| 风、尾流与冲击 | 有尘、雾、草叶、水面、衣发时借它们显示传播，写清源点和方向。移动的波前经过后才出现相应摆动 |
| 火星、尘粒、碎屑与拖尾 | 指定材质、源点、疏密、散开方向、碰地和消退。实体的位置和逐渐消散的拖尾分别写清 |
| 光束、脉冲与飞行光体 | 确定是持续的连线、短暂光段或独立移动的体积。写起点、去向、主体尺度、终止或偏折，以及邻近表面的局部受光 |
| 火、烟、蒸汽与热扰动 | 火、烟和薄气流各有起处与速度；可见热扰动留在相应区域。纯机械碎裂可单用碎块与尘，按剧情决定火光 |
| 水、浪、喷溅与其他液体 | 从水量、厚薄、加速和回落下笔。大体积翻动与边缘飞沫分开，厚薄决定透光和反射，受障碍时写绕流或拍击 |
| 闪电、电弧与魔法电光 | 确定主要通路、端点、短支与熄灭。身边物体仅按所在位置受闪光和遮挡，端点随它依附的表面移动 |
| 破损、崩落与地表裂变 | 指定局部受力、结构厚度、支撑和可变化边界。石头看裂边、碎块和灰屑，木头看顺纹分开，金属看弯曲或位移，玻璃看透明碎片。保留主体和残留的位置 |
| 冰、结晶、沙尘与表面变化 | 写生长、冻结或脱落从哪处向外发展。用薄霜、厚晶体、表面湿痕的差异表现阶段，沙粒按风向和阻挡聚散 |
| 雨、雪、雾、云 | 风与重力方向统一，前中后景的密度、大小、清晰度与遮挡有区分。同一世界的云雾和衣发可以有局部差别 |
| 护盾、法阵、传送与科幻显示 | 确定附着对象、平面或体积、透视和遮挡。接触反应从实际命中点发起；穿出、耗散或改变路线按已定世界观 |

混合效果先定主介质与必要变化，再择一两种辅助层。面对「特效很廉价」的反馈，先找可观测的问题，如屏幕贴片感、全程同亮、密度平均、接触提前或残留清零；优先修相应镜头的视差、遮挡、主次、触发和接镜。拍摄震动、闪光和变速要有动机和回落，精确到帧时交给后期时间线。这些写法描述画面目标，具体执行按样片验收。
