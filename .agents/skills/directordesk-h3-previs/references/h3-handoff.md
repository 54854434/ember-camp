# 编剧交接与 1160 视频参考

## 给写剧本的对话

下面这段可直接发给专门写提示词的另一个对话。

> 你负责给 MiniMax H3／ComfyUI 1160 写定稿。根据我给的创意、人物和素材写出两部分。
>
> 第一部分给我可粘贴的 1160 提示词。每个连续生成的分段用成对的 `[SHOT_START]`、`[SHOT_END]`，里面写 `===H3_PROMPT===` 以及 `===SCENE_INSTRUCTION===`、`===VIDEO_INSTRUCTION===`、`===AUDIO_INSTRUCTION===`，没有素材的调度区写 `{"slots":[]}`。只有真正切镜才另写 `[Shot N] At mm:ss.mmm`，单镜内写清动作顺序和触发关系。保持原定时长、画幅、角色、对白和素材职责。已提供的真实素材按其实际槽位保留。白模还没生成时，在第二部分写清需要它控制的站位、路线、动作接点、镜头路径或切镜节奏。素材引用按实际绑定填写。
>
> 第二部分给 DirectorDesk 预演用的分镜清单。逐镜写清切点或大致时长、固定场景地标、人物开镜与收镜站位和朝向、谁先做什么及对方怎么回应、人物走哪条路线、机位看向哪里和怎么移动。对白与关键音效单列。把定稿交给我，我会交给另一个对话来生成 `.director` 和白模参考。

可使用普通剧本文字或同一本地工作区的 Markdown 交接。不同对话的草稿和定稿以交付文件或明确贴出的正文为准。

人物调度用[站位与真人表演](../../video-scene-direction/references/performance-and-blocking.md)把画面左右落到固定场景地标上。复杂镜头可补俯视示意，注明人物朝向、视线、持物、承重和摄影机的起幅与落幅。说话人、完整台词、画外声和关键拟音在清单中单列，内部估时按[对白时长与切镜](../../video-scene-direction/references/music-and-sound.md#对白时长与切镜)核对。切镜后的同一个道具和人物继续从上一镜的实位、姿态和状态接起。

## 从白模生成 Ref2VA 提示词

1. 拿到实际节目机位白模 MP4 后，在 1160「参考素材管理 → 视频」里添加并启用，给它一个可区分的名称，保存后读取真实槽位。用户只要提示词时交付素材绑定表和完整提示词，用户要求接入时再改目标工作流。已打开的工作流有未保存编辑时，从当前工作流状态操作或另存，避免旧 JSON 覆盖当前设置。
2. 使用管理器的「穿透生成模式」。完整 1160 分段用 `===VIDEO_INSTRUCTION===` 按实际视频槽顺序填 `slots`。例如白模是视频 A 时用 `{"slots":["视频:视频A"]}`，此段正文引用 `<Video 1>`。角色图片继续写入自己的 `===SCENE_INSTRUCTION===` 及 `<Picture N>`。`<Video N>` 与 `<Picture N>` 各自按该段实际绑定顺序从 1 开始。用界面插入真实 `@` 条目也是一种绑定方式。导演台提示词的 `@视频1` 是交接约定，接入前核对槽位并换成当前工作流可识别的引用。
3. 使用 Ref2VA 六字段时读取已安装 `h3-visual-prompting/references/h3-formats.md`。正文写明视频提供运镜、切镜和走位，白模颜色只用作身份映射。保留用户的真人参考、服装、场景材质、对白和声音。模板里的影片编号在素材真实存在、顺序核对后才使用。音频单独绑定，只在用户提供时引入。
4. 参考视频输入是条件，成片跟随程度要看实跑结果。若已授权跑 H3，先核对 Ref2VA 模型与音视频 VAE 接线、日志里实际绑定的视频数量，再对照关键动作和切镜结果。不确定请核对本机 `ComfyUI/custom_nodes/ComfyUI-JZL-MiniMax-H3/nodes_asset_manager.py` 和 `sheding/h3_shot_rules.py`。

## 有效参考时长

本机 1160 的视频加载器按 24 fps 抽帧，最多取最前面的 240 帧；当前 H3 编码还会将可用帧数裁到不超过上限的 `17k+5`，并受一采生成长度限制。当前配置里 240 帧的白模可以进入编码的通常是 226 帧，约 9.42 秒。把结尾关键动作放进有效帧内，或在余尾留停顿。15 秒成片与当前参考上限分别处理，需完整覆盖的长参考可以按已确认的分镜拆段。

对实际 MP4，可从本地工作区运行 `scripts/check_reference.py`，传视频文件和可选的 `--h3-seconds`。工具用 FFmpeg 解码到空输出并给出预计实际保留帧数。若插件已更新抽帧常量或对齐规则，先核对上面的本机源文件。
