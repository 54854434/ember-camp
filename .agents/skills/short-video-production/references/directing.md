# 导演分镜与审片

从编剧需要观众接收到的信息出发，确定从谁的处境进入这场戏，再决定怎么拍、何时切。场面的主观视点可以来自构图、表演反应和声音；只有需要借用角色眼睛观看时才使用光学主观镜头。

要查具体运镜、景别、正反打、轴线、反应镜头和声音切法，先看[拍摄与剪辑技法速查](camera-and-editing.md)。

## 分镜前的四个决定

| 决定 | 先回答的问题 | 会改变的拍法 |
| --- | --- | --- |
| 观众跟谁 | 此刻要靠近谁的感受，观众和他各知道多少 | 同一句话可以留在说话人脸上，也可以切到接收信息的人 |
| 第一次看见什么 | 新线索、状态变化或空间关系什么时候能被看清 | 开门前先听到声响可以推迟揭示；先给把手特写可以让观众领先人物 |
| 表演怎么被看见 | 哪个动作、停顿、眼神或站起坐下使关系改变 | 先用站位、距离、遮挡表现关系，再看是否有必要推镜或切特写 |
| 剪辑有哪些素材 | 哪一镜承接前后动作，哪一镜提供必须的信息或反应 | 有空间关系需求时留一个交代位置的镜头；关键道具状态或人物选择另留可剪素材 |

导演可以通过站位让人物在群体中的处境变得可见，也可以在新信息出现时将重点交给听者的反应。 [DGA 关于《傲骨贤妻》的导演实践](https://www.dga.org/craft/dgaq/issues/1302-spring-2013/the-good-wife) · [Taylor Hackford 的分镜回顾](https://www.dga.org/news/guild-news/2026/craftarticles/0926-shot2remember-ray)

## 导演镜头卡

| 镜号与时长 | 叙事功能、所跟视点 | 入镜状态与可见表演 | 相机、走位和声音 | 出镜状态与切点 | 必保证据与可用替代镜头 |
| --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |

- 做对话时先定人物和相机轴线，核对视线方向、景别与动作接点。选择越轴或换位时，让观众通过中性机位、清晰的运动或重新建立的空间关系理解变化。
- 切反应镜头之前想清表演重心。如果关键是主角听明白了什么，可以把发话声留在画外，先看接收者的眼神或动作。若要保留迟疑和尴尬，可以在同一构图里多留半拍。试节奏时同时听声音和看图，避免按对白句号机械切镜。
- 剪辑先看情绪是否到达、观众是否弄清因果、节奏是否给了足够的反应时间。切点依表演和故事变化移动。环境底声可帮助接镜，上一场声音延续或下一场声音提前进入时要有叙事作用。 [Walter Murch 与电影剪辑师工会期刊的访谈](https://cinemontage.org/visual-music-walter-murch/)

## 先准备资产再完成分镜导演稿

适用于用户需要从剧本、分场或一套素材推进到实际分镜，尤其是需要 Codex 随制作生成参考图的任务。已有分镜或已确认资产时从可用阶段接续。以下步骤共用场次与资产编号。

1. **提取资产及用途。** 根据分场先列出确实要上镜的角色、服装、场景、道具及状态变化，核对光色和会影响走位的固定地标。每项写「编号、版本、来源或生成任务、用途与必保特征、使用场次、当前状态」。把只出现一次的背景装饰留给场景图。先列出关键画面需要的视角和信息，方便确定要画正面、反角还是局部状态。
2. **准备可用参考。** 优先核对已有素材。用户要求从项目做到可用图时，调用当前可用的图像工具补缺，按[参考素材与连续性](../../h3-visual-prompting/references/reference-assets.md)检查身份、服装状态、布景几何和道具尺度，把实际文件路径及版本写回清单。区分待出图、已生成待核对和已核对可用。关键资产暂缺时，以清单继续设计可推进的镜头，指出需要以成图复核的构图。
3. **拆分镜组。** 按观众需要看见的连续行动组织镜组，优先让共享地点、状态与动作接点的镜头在同一组。每组交代镜号范围、叙事任务、时长、资产编号和版本、开头及结束状态、跨组继承与缺图。机位仍需验证时，先对照实际图核对所需墙面、通路或反角，再选最合适的分镜。
4. **组装导演稿。** 对照分镜组和实际素材逐镜填写[导演镜头卡](#导演镜头卡)。确定景别、走位、可见表演、机位与切点、对白与拟音，然后逐镜核对取景里真能看到的目标与地标。修改单项素材时按编号回查受影响的镜头、相邻接点和已有提示词。

导演稿按用户所需交付。需要 H3 提示词时，将镜头证据与真实文件、引用职责交给调度台，再接 1160 素材槽。模型标签以工作流绑定次序为准。

## 预演、生成与审片

1. 先用走位草图、对白试读、静帧和临时声轨验证动作和时长。竖屏检查脸、手、道具和字幕是否在同一关键瞬间都能看见。先找到不可少的镜头，再决定补多少覆盖。
2. H3 一次生成困难的镜头时，用镜头卡说明哪些是叙事必需，哪些可交给后期。长动作拆段时写清前一段结束状态与后一段开头状态，给动作剪点留可用素材。口型、手部交接、群演背景等问题可以用反应、动作结果、画外音或独立特写替换，保留观众判断所需的信息。实际语法和参考绑定由 [h3-visual-prompting](../../h3-visual-prompting/SKILL.md) 处理。
3. 审片先从头顺放一遍，再按时间码定位。若观众缺一个事实，补能传达它的动作或镜头；若事实已懂、感受不到，优先试表演、反应、声音或截点；若同一人物变脸、物件跳位或执行错误，再回到参考素材与生成参数。每条反馈写成「时间码、观察、影响、最小修改」。

交付字段跟随[制作与运营手册](production-playbook.md)。试片要求同时包含视觉和声音时，分别标出必须留在生成镜头中的同步动作及可交给后期的声层。
