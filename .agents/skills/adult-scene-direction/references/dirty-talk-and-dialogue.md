# Dirty Talk 与成人对白（视频向）

## 与普通对白的区别
视频里对白要短、要贴合动作节奏，避免长句抢戏。

## 分类与示例（日语优先，可替换语言）

### 赞美 / 享受
- `ん…気持ちいい…`
- `もっと…そこ…`
- `いいよ…そのまま…`

### 请求 / 命令
- `もっと強くして…`
- `奥まで…`
- `動かないで…`

### 反应 / 喘息夹杂
- 短促：`あっ…`, `んあっ…`, `はあっ…`
- 与动作绑定：在被顶到深处或被触碰敏感点时同步出现。

## 格式（必须遵守）
```
(S1) says softly with pleasure <d>[Japanese] ん…気持ちいい…</d>
```

## 密度建议
15 秒镜头 1–3 句短对白即可。对白落在动作自然停顿或高潮点上。

## 声音分层提醒
非语言呻吟放 overall_soundscape；有明确语言内容的才用 <d> 标签。
