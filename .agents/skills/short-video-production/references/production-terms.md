# 视频制作术语与应用

查合同、后台指标和工具功能时以当期来源为准。工作用语落到可交付的东西上，例如有时间码的反应镜头、带版本的角色参考图、可以对回成片的留存片段。

| 岗位 | 常用术语及应用 | 交付中写清什么 |
| --- | --- | --- |
| 热点编辑与内容研究 | **热度、榜位、播放量**分别记平台原指标。**增速**用同项指标、同对象和两个带时间的记录计算。**基线**用相近作品和相同发布年龄作参照 | 原帖、观察时间、可比范围、离热点窗口结束还有多久 |
| 创意策划 | **钩子**是观众开头遇到的待解问题。**观看承诺**是他继续看预期会得到的东西。**系列机制**说明固定角色为何能在不同单集碰到新问题 | 首镜、单集变化项、结尾的实际回报 |
| 编剧 | **节拍**是行动、关系或信息发生变化的一拍。**伏笔与回收**安排观众何时看见线索、何时理解它。**潜台词**是人物真正的意图，可通过停顿、行动和反应表达。**单元与主线**分别记录当集收束和跨集变化 | 每场的起止局面、人物选择、观众知情量、可拍到的证据 |
| 制片 | **拆解表**把剧本落实为角色、场景、道具、效果和工序。**预演**用低成本素材验证时长、走位、接镜和声音。**补拍或补生成**针对粗剪指出的缺口 | 优先验证的镜头、返工原因、实耗与可用的成片秒数 |
| 导演 | **视点**决定观众跟着谁理解事件。**走位**安排人物和物体相对于空间及机位的行动。**镜头覆盖**是能剪出该场戏的一组主镜头、近景、反应和细节 | 切点需要什么新信息，哪一镜必须看见，道具与人物在画面哪边。详见[拍摄与剪辑技法速查](camera-and-editing.md) |
| 视觉美术 | **角色设定稿与三视图**固定身份、比例和主要装束。**色彩脚本**安排不同场次的色彩与光线如何随剧情变化。**形状语言**用反复出现的轮廓帮助辨识角色和物件。**场景平面图与状态图**分别交代空间关系与物件使用前后 | 固定识别点、可变状态、主光方向、重点道具和对应参考编号 |
| 场记与连续性 | **场、镜、条**分别指叙事场次、镜头单位和该镜头的一次拍摄或生成。**动作接点**是前后镜要对齐的姿态和动作阶段。**视线与运动方向**帮助剪接维持地理关系。**接戏**核对服装、道具、时间和人物状态 | 镜号、选用条与参考版本，入镜和出镜的可见状态，需补拍的一侧 |
| 剪辑与声音 | **粗剪、精剪、锁画**分别用于验证叙事、打磨细节、冻结最终时间线供后续工序使用。**同期声、补录对白、拟音、底声**分别处理现场人声或环境、重录对白、动作音和持续空间感。**响度、峰值**分别检查整体听起来的音量和短时突出的信号；按交付要求核对 | 时间码、改动轨道、可独立调整的对白和声音层、母版版本 |
| 平台运营 | **曝光与点击率**用来排查入口包装，**留存和完播**分别观察特定时间点与整段表现。**A/B 测试**有分流或相当实验设计时使用。一般前后比较需标注发布窗口、流量来源和其他变化 | 平台版本、后台指标名及分母、掉点或峰值时间码、一次验证什么 |
| 发行与版权 | **母版与平台版**对应工作源和渠道交付。**授权链**记录素材来源及各方允许的用途。**地域、期限、独家和结算口径**分别落实到合同。**AI 声明与标识**按适用规则和平台表单核对 | 文件版号、来源或授权凭证、实际投放渠道、对应的声明和待确认项 |

## 按任务快速定位

- 「这个开头不好」先查[编剧开发与审稿](screenwriting.md)里的节拍和观看承诺，再用后台留存验证是否真在开头流失。
- 「说话和出招该怎么切」查[拍摄与剪辑技法速查](camera-and-editing.md)里的正反打、反应镜头、动作匹配和声音桥，再把规则写成视线、方位和动作接点。
- 「人物漂亮但接不上」核对角色参考版本、轴线、视线、动作出入点，再做补镜或替代拍法。
- 「两边都要发，怎么复盘」从[后期交付与平台复盘](postproduction-and-review.md)的母版和版本记录出发，各平台用各自后台口径。

国内平台的指标和工具功能可从平台原文核查。角色分工、交付和国内创作案例见[国内创作分工实践](china-role-practice.md)。 [B 站数据中心口径](https://www.bilibili.com/blackboard/activity-0ONDyIXVCl.html) · [剪映官方功能](https://www.capcut.cn/) · [短剧创作者中心](https://www.shortdramas.com/)
