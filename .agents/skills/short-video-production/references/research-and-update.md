# 公开数据研究与更新

## 如何统计高流量作品

1. **先明确要验证的创作问题。** 例如找同题材高播放短片的开头规律，或比较一集一转折与多集一悬念。确定平台、题材、内容形态、时长带和发布日期范围。未定题材时可先把多个方向放到并列的样本组，说明试采范围。
2. **从可打开的原帖和平台榜单取样。** 用榜单、相关关键词、创作者主页和近期常规作品补齐样本。用原视频链接或视频 ID 去重。同素材的多平台版本分别记录。优先保留同平台、同题材、相近时长和发布年龄的可比样本。保留一些常规表现作品，减少只看赢家造成的偏差。
3. **留原始证据。** 保存抓取时点、样本来源和页面可见数值。播放量显示为「1.2 万」时保留显示值，并把转成的数标作约数。公开数据缺失填「未公开」。显示点赞时可以做点赞量排行；只有能核实播放量的样本才进入播放量排行。后台留存、完播、转化、投流金额及收入需有对应证据。
4. **在组内比较。** 公布每组样本数、有播放量的覆盖率、统计区间和中位数。看近期作品时匹配发布年龄，同时参考作者同档历史表现，标注头部账号、投放或联动等可见影响因素。有可靠的同一观察窗口和可比的账号基线时，可计算单条播放量除以该账号匹配作品的播放量中位数。互动比例优先分别列点赞数除以播放量、评论数除以播放量；说明分母和有效样本数。平台间分别展示指标口径与数据可得性。
5. **逐条回看片段并编码。** 记录异常或冲突出现的时间、首个叙事承诺、主要转折、结尾回报、催更方式，以及对应片段时间码。输出能看见的重复做法和可解释的例外，给每个建议附原帖证据和原创改编方向。热度和叙事手法的关联仍是待验证的假设。

### 样本记录字段

| 类别 | 建议记录 |
| --- | --- |
| 定位 | 平台、标题、原帖、作者、题材、形态、时长、发布时间 |
| 取样 | 检索词或榜单、采样时间、发布年龄、样本组 |
| 公开数据 | 播放、点赞、评论、收藏、转发，按页面实际展示填报 |
| 结构 | 首帧、冲突出现时间、角色行动、转折、结尾回报 |
| 判断 | 证据时间码、可能的混杂因素、可迁移手法、原创验证方案 |

**把观察变成一次可尝试的改动。** 例如公开案例里多条作品先展示道具异常，再补充人物背景。为自己的原创故事写一个「先拍异常道具」的开场，并用同一账号、相近时长的早期留存数据复盘。参考公开作品的叙事机制和呈现方式。复用具体台词、角色、画面、音乐或情节表达前核对授权。

## 查平台规则与商业合作

运营动作受规则影响时，优先查主管部门文件、平台官网和登录后台。交付时给出页面链接、条款适用对象、生效日和查询日。后台仅对相应账号展示的资格与权益，按该账号的可见信息确认。平台公开介绍可以用来核对合作路径，分账比例、独家范围、结算周期与授权期限按具体合同核对。

下列公开入口于 2026-11-23 查阅。具体规则与账号状态在行动前复核。

- 投稿与 AI 标识入口从抖音官方页面查找。[抖音创作者中心](https://creator.douyin.com/) · [抖音规则中心](https://www.douyin.com/rule/policy?activeId=billboards)
- 投稿、稿件审核和收益根据 B 站官方入口及对应账号的创作中心确认。[B 站创作中心](https://member.bilibili.com/platform/home) · [B 站客服中心](https://www.bilibili.com/h5/customer-service/home)
- 红果相关的短剧合作身份与服务范围查看平台公开页面。评估成品合作时单独核对交付、审批或备案、版权和结算。[短剧创作者中心](https://www.shortdramas.com/) · [广电总局《微短剧发展管理办法》](https://www.nrta.gov.cn/art/2026/7/31/art_113_73785.html)
- 含生成合成内容的稿件按法规和目标平台当期流程声明。[网信办《人工智能生成合成内容标识办法》](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm)

## 把发现更新进技能

- 热榜、竞品数据与一次性案例写进当期调研；跨样本反复成立的做法，或在自己账号验证后能复用的流程，才写进长期参考。样本范围不足时保留观察及待验证问题。
- 核心技能保留调用范围和稳定流程。平台规则变动更新到本页，注明来源、核对日期、受影响的步骤和旧口径何时失效。涉及模型或素材商用时查对应版本的许可原文。
- 应用户要求更新时，先核对当前版本与证据，修改相关条目和失效链接，校验后同步用户授权的技能仓库。提交说明写明改变的工作方式。账号凭据、未授权素材和创作者后台数据留在适用的私密位置。
