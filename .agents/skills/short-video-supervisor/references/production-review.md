# 从美术资产到 H3 终稿

适用于需要多岗位配合的完整镜头、分镜组和反复失效的关键镜头。编剧说明观众为何在意这场戏。美术定义已确认的可见形态，表演指导确定人物何时行动，摄影决定观众从哪里看见变化。只在当前场面需要时读取相应技法，使用同一份分镜安排。

## 资产表演与摄影的联合核对

| 工作 | 出稿前做的决定 | 如何看到它实际生效 |
| --- | --- | --- |
| 故事与分场 | 用[剧本压力测试](../../short-video-production/references/screenwriting.md#生成前的剧本压力测试)找出视听回报及改变观众判断的证据。核对伏笔在何时被看见、角色何时知道、结果何时兑现 | 该留的铺垫与结果在对应的镜号各有可指认的动作、声音或道具状态 |
| 美术与静帧 | 用[静帧写法](../../h3-visual-prompting/references/reference-assets.md#为静帧选择模型和写法)决定图像要解决身份、场景、构图还是局部状态。多格图先核对用哪一格。关键起幅需要控制时查[走位到首帧](../../video-scene-direction/references/performance-and-blocking.md#从平面走位到可生成首帧)及实际模式 | 参考编号能找到真实文件及当前版本，图中可见的外形和位置符合职责。角色服装和关键物件只在用户指定的触发下改变 |
| 表演与声音 | 按[表演动机与动作](../../video-scene-direction/references/live-action-performance.md#把表演动机变成可验收的动作)选目标、策略及触发反应。分开当前表演、固定音色和当句台词。只有人物当下可见或可听的行为需要进正文 | 画框能见到反应的部位，开口前后顺序可读。原文按说话人落在镜头内，连续反应和物件状态跨镜接上 |
| 空间与摄影 | 从首帧列出在画内、在画外、待入画的人，各自对齐地标、视线和手中物。按[镜头任务和视场](../../video-scene-direction/references/camera-and-cutting.md#由镜头任务决定视场和清晰面)选机位、路径、焦点及有动机的光源 | 能在文字或有效参考里推导画面左右、遮挡和光影。模型收到的正文写明何时移动、末幅露出什么。实际切点按机位和新信息决定 |
| 因果、剪切与现场响应 | 导演稿逐拍检查谁改变了什么。每个关键反应有自己的触发位置、传递过程和末态。按内容决定硬切、动作匹配、声桥或其他真实转场 | 英文镜头中的背景运动、材质变化、声音和站位接点能逐一指回中文执行稿。背景没有必要变化时明示持续状态。有需要的出入画按故事安排 |
| 模型交付 | 核对[四阶段成稿](../../video-scene-direction/references/prompt-enhancement.md#h3-四阶段成稿)、[实际 H3 模式](../../h3-visual-prompting/references/h3-formats.md#选择提示词模式)及 1160 调度。按可见目的删去过期角色、前情台词、副本标签和无关修饰 | 每项关键要求可以定位到「镜号、英文句子或真实文件、成片中如何核对」。静帧生图语言与视频正文语言分别依各自任务 |

## 把导演模块放入实际 H3 字段

- **基础模式。** 把当镜场景、人物、起幅、机位、动作、可见反应和同步声写进 `integrated_multimodal_description`。有首尾帧的模式依官方位置写对齐语。连续声景和非叙事配乐各用对应字段。
- **Ref2VA。** 主体定义登记身份与实际参考，摘要交代任务和素材用途，保留分析说明继承或允许改变的特征及对应镜头。首帧构图、摄影、按时间发生的动作、灯光随位置的变化、对白和现场反馈写进 `detailed_description`。连续环境声与非叙事配乐分别填写。只在主体定义写过的动作或只有摘要提到的接点，应落实到发生的实际镜头。
- **1160 封装。** 片头标题、时长和说明供人和控制台阅读。穿透生成优先核对 `===H3_PROMPT===` 实际送入的正文。英文转写时保留原台词、写给观众看的原字，以及准确的素材名。单一连续镜头沿同一镜号用动作触发表达先后。真正换镜按相应模式写切点。素材由同块外层调度绑定，再核对真实编号、引用职责和生效位置。

ISO、镜头品牌、风格后缀、固定字数与固定光学数字是特定工作法里的可选表达。需要画面变化时优先给出相机与主体位置、近远地标、可辨认材质和光位。需要压缩时先删重复描述和不在本段生效的内容，保留辨认身份、动作因果和前后镜连续所需的证据。按实际工作流处理负向输入与准确声音引用。

## 针对常见偏差核对最终正文

| 发现的问题 | 直接找到正文里的验证条件 |
| --- | --- |
| 切后人物换位、地标消失 | 查两镜的同一固定地标、人物实位、遮挡和动作阶段。必须贯穿背景的地标在新镜头仍有可见位置时，写清它在切后画面哪一边。出框的地标用原有空间关系定位 |
| 背景不动、异常变化或反馈错归 | 为独立背景运动写动因、可见部位和落幅。两种反馈共用材质时，分别核对接触处、起势时机、传播方向和量级。给保留的损坏或残余运动一个尾镜证据 |
| 运镜变成裁切，或预演没有带动机位 | 查镜头路径有无固定地标与近远视差，再确认接到模型的确实是负责运动的实际视频或关键帧。只有文字绑定名时还需确认已加载素材与入口职责 |
| 台词多了、晚了，或听者也动嘴 | 查实际发声位置、`<d>` 原文和说话人。核对反应的触发时机以及说话后闭唇或下一动作。样片时分别判断额外人声与画面口型，定位生成与后期各自的修改位置 |

## 原资料的适用边界

- **Hell Grind 原版与洋子 V2。** Lira 的解构和诊断适合静帧。原版的模型分工依 Higgsfield 等入口，V2 增加了中文化和项目构图及篇幅偏好。按任务取用。ACTING 的目标、策略、反应和角色档案用于导演设计，可见表现写到模型正文。原包的长档案、固定声音段落、节拍数量和魅力分数按实际剧情、时长及声音入口决定用途。
- **CINEDANCE。** 十余项模块为分镜检查提供顺序。影像标准、视场示例、默认硬切及禁止表属于其工作流取向。移植到 H3 时先定真实镜头与同镜内的动作，再映射实际字段。可见穿行、转身、遮挡与已建立的新地理允许重算画面左右。主动入场和有明确动机的空镜继续按剧本设计。
- **走位与剧本压力测试。** 走位包对跟随站位图和画风串入分别测量，入口记录不全。本机试验按[走位图研究记录](../../short-video-production/references/technique-findings.md#走位图到底能控制什么)。剧本包的因果、移除节拍与最小改写适合诊断，峰值比例及反转间隔需对应具体类型和样片。
- **Infinite Canvas 与资产到分镜。** 多机位图供选择，节拍图供排演，出片所需单格与版本从已核对资产中取。备份主参考与镜号清单，按[资产到导演稿](../../short-video-production/references/directing.md#先准备资产再完成分镜导演稿)标明来源及实际用途。
