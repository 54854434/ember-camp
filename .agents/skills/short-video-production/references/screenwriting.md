# 编剧开发与审稿

根据用户当前交付选用工作深度。一句点子可以从梗概开写，一场戏可以直接诊断和改写，系列项目才需要逐集梗概和设定记录。先确认用户的原意、已锁定的情节与可修改范围。

## 从选题变成有因果的故事

1. 写清观众进入这条短片时看到的问题，谁急着解决它，失败会损失什么。异常本身可以是钩子，主角接下来的选择决定它能否成为故事。
2. 顺着「发生什么 → 人物怎么应对 → 这个应对造成什么」检验主要节拍。如果两个事件只靠时间先后衔接，补上角色为什么选择下一步，或删掉不影响走向的一拍。反转要由观众见过的线索、规则、性格或已发生的动作支撑。
3. 校准观众的知情量。悬疑里记录观众此时知道什么、主角知道什么、哪条线索必须提前出现。喜剧里记录观众以为接下来会怎样、角色是怎么认真执行的、哪一拍打破预期。情感戏可以让一次行动或态度变化承担结尾。
4. 先确保结尾兑现开头的承诺。单元剧在当集落实主要结果；有跨集主线时，留一个来自本集结果的新问题。集与集之间可延续同一人物的习惯、关系或累积后果。

以选择和局面变化推动叙事，结构跟随故事需要。 [Craig Mazin 关于人物选择与结构的 Scriptnotes 讲稿](https://johnaugust.com/2019/scriptnotes-ep-403-how-to-write-a-movie-transcript)

## 场次卡

审一场用一行，短片也可把关键节拍填进同一张表。

| 场次 | 进场时的局面与信息 | 人物要什么、有什么阻力 | 可拍的行动或选择 | 出场后改变了什么 | 下一场依赖的画面、声音或台词 |
| --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |

- **做删场测试。** 暂时抽掉这场，看后续因果、人物关系或情绪转折缺了什么。如果影响很小，可合并到另一场。保留下来的场次，尝试从已经发生变化的时刻进入，人物做完决定或观众收到关键信息就考虑切出。 [John August 的场次写作流程](https://johnaugust.com/2007/write-scene)
- **做对白试读。** 标出每句的意图，例如拖延、试探、确认或掩饰。朗读并把停顿、对方反应及必要动作一起计时。可改写的草稿可去掉表演和道具已交代的信息。已确认对白逐字保留，有时长冲突时用[对白估时与切镜](../../video-scene-direction/references/music-and-sound.md#对白时长与切镜)单独复核。情节需要人物误会时，观众仍要能从画面听懂误会的原因。
- **做制片判断。** 阻力可以通过画外声、一个反应或道具结果交代。改轻量拍法时保留人物的选择和观众必须看懂的证据。照样需要多人交互、严格口型或复杂场景时，把最可能影响成立的镜头先列给导演试片。

## 系列规模与交接

- 剧本按集、场、事件、镜头逐层拆解。每场记录新信息与改变的状态，镜头承担可见动作、反应或线索，生成段再按实际工作流能力分组。可在同一场中多次生成。真实转场涉及新场景资产或布局时优先组织为独立生成段。用户指定长镜头跨区时，先核对连续空间路线与素材，再决定实现方式。
- 独立单元用系列设定卡、常驻角色卡和每集简短梗概。跨集主线较重时补一张因果和伏笔表，记下铺垫、观众知道时间、角色知道时间、兑现集和改动影响。按项目规模选文档。 [Screen Australia 剧情项目开发文件指南](https://www.screenaustralia.gov.au/getmedia/133af42b-7abe-4ebc-a164-799c1c7a4614/Story-Documents-Drama.pdf)
- 写国内生活题材时，为角色的选择找一两个本地生活细节，例如职业习惯、办事顺序或家庭称呼。优先保留会影响人物行动、观众理解或镜头可拍性的细节。准备递交国内短剧征集或合作时，按项目当期要求组织梗概、人物小传、集纲和剧本。先在梗概里交代主线、冲突与结局，再让分集稿证明这套人物关系能持续长出故事。 [中国网络视听节目服务协会刊载的微短剧行业调研](https://www.cnsa.cn/art/2026/10/9/art_1955_49387.html) · [国内微短剧征集材料示例](https://www.cnsa.cn/art/2026/9/4/art_1955_49272.html)
- 交导演时明确三件事：这场结束后世界哪里变了、观众什么时候必须知道、哪项表演或视听证据必须出现。景别、机位和剪法留给导演方案。改稿交付时把会影响现有分镜、集序或角色设定的变化标出来。
- 做固定人物单元剧时，用现有[单元剧与角色预设](unit-drama.md)管理持续信息。收到「先搭基础」之类的任务时给空白卡和流程。
