## 美术与交互工作线

美术可与P1穿插，但以一个可玩的营地—荒野样板区为单位。当前只有首轮地表、树木和营地UI。

1. **ART-01 样板规格**：相机比例、人物尺寸、建筑格尺度、地表过渡、色板、光色、遮挡与点击反馈统一。
2. **ART-02 可玩样板区**：角色行走/开火/受击、感染者状态、六类主要建筑与破损态、道路/林地衔接、可交互物标识。
3. **ART-03 氛围与声音**：营地暖光、荒野冷色、天气层次、枪声/脚步/尸群方向反馈；在真实机型上确认成本。
4. **UX-01 手机完成度**：安全区域、触控热区、自定义位置/尺寸、菜单滚动、资源展示、明确的损失与错误反馈。

验收需要实际引擎渲染、可操作场景、用户观感与机型记录。单张生成图或一张界面截图不算整款游戏达到精品品质。
