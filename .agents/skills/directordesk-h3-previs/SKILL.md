# DirectorDesk 白模预演与 H3 多参

接收另一对话交付的剧本文件、H3 正文或完整 1160 分段块。用户提供普通文字即可，由当前对话把剧情拆成可执行的白模动作和摄影视图。尊重定稿的角色、场景、顺序、对白、时长和画幅。缺少精确坐标属于导演编排，缺少会改变剧情的关键信息才需要确认。

- **制作工程**时读 [DirectorDesk 工程与导出](references/directordesk.md)。优先复用已安装版本的官方工程工具。把人物路线、动作片段、机位、视线和切镜写入真实时间轴，交付能打开的 `.director`。工程结构校验和实播核对分别记录。
- **导出白模**时沿用已授权的本机 DirectorDesk 能力。核对节目机位、切镜和目标文件。完成后交付实际 MP4；运行环境不可用时交付已验证工程和具体导出入口。
- **接入 1160** 时读 [编剧交接与 H3 视频参考](references/h3-handoff.md)。明确白模负责构图、走位、运动节奏和切镜，真实人物外形和材质交给用户的参考图与正文。核对实际槽位、视频编号与有效帧数后交付能用的 Ref2VA 提示词或在已授权的工作流里绑定。
- 仅需要编剧交接文案时，用 [编剧交接提示词](references/h3-handoff.md#给写剧本的对话)。仅写 H3 提示词且无需工程或白模时，使用同一安装目录下的 `h3-visual-prompting`（若已安装）。

本机工作区通常为 `D:/comfyui`，交付可放 `work/片名/`。先按用户需求判断哪些产物需要实际创建。角色动作和机位有疑问时优先核对关键帧、摄影视图与原剧本。
