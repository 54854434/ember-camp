# 用户真机试玩清单

不要求模拟器，也未进行 Android 安装测试。以下用于真实手机试玩反馈。

## 已收到的设备信息（2026-11-08）

用户报告：iQOO 11、OriginOS 6（原文Origin6），安装本对话最近构建ZIP中的APK。具体构建编号/文件哈希、Android底层版本未知；安装已报告，菜单点击、多指与画面适配尚未确认。

本轮先收集三个结果：①营地整备/背包/暂停能否打开和关闭；②能否边移动边开火；③文字/按钮是否被裁切或被摄像头区域遮挡、是否容易误触。记录实际异常和大致位置；用户可任选反馈，不强求完成整套检查。暂不要求死亡或删档测试。

## 完整试玩清单（按需）

1. 安装 APK，确认中文无方框、横屏界面无遮挡；记录机型、Android 版本。
2. 进入世界，用左下区域拖动移动，按住右下开火；确认能同时移动与开火。
3. 未建造、未撤离前外出，找一块空地，面向计划位置点“扎营”；确认回营指向和核心位置改变。
4. 开启建造，放置围墙、工作台、门与路障；确认材料减少、已有格和材料不足时不能建。
5. 在门附近点搜索，切换开关；关闭能挡路，打开能通行。
6. 找补给箱搜索，背包达到重量上限；丢弃一件物品，再搜索剩余物资。
7. 返回营地按住撤离四秒，确认物资转入仓库；再次撤离不能重复领取。
8. 触发布防演练，观察丧尸靠近、攻击防线；确认尖刺和炮台有效，且弹药与燃料减少。
9. 测试受伤、出血、药品、进食、换弹和近战；注意哪些按钮容易误触。
10. 外出携带物资时关闭并重开游戏；核对营址、建筑、已搜容器、随身物资和位置。
11. 暂停或切后台一段时间，确认基地不在离线时被攻击。
12. 记录失败的具体位置与操作，以及是否看清损失原因。截图可选，优先给出“做了什么 → 看到什么 → 期望什么”。

优先反馈：能否理解目标、触控是否可靠、物资是否过剩或不足、围墙是否过强、炮台耗弹是否合理、选址是否有实际影响。当前地形策略仍浅，水源、污染、运输和完整寻路属于后续迭代。
