# 《余烬营地》游戏框架 v0.1

此文件保留玩法设计。实际已实现与待验证状态见 [PROJECT_STATUS.md](PROJECT_STATUS.md)，按 [ROADMAP.md](ROADMAP.md) 的验收标准继续开发。

## 产品定案

Android、横屏、离线单机、俯视角实时战斗。最终视觉可以发展成斜俯视 2.5D，但原型先验证操作、战术和经营循环。主角是聚落的外勤与建设者，硬核来自损失、后勤和信息不足，不靠无限叠加操作负担。

一局远征目标约 10–20 分钟是设计目标，需试玩验证；世界、基地、物资和人员成长跨远征保留。暂停和离线不产生惩罚。

## 自由选址与持久基地

基地是大世界中的实体，丧尸能沿世界空间靠近并损坏设施。原型保留临时核心，允许玩家先探索，再将核心放到任意满足空地与安全距离要求的位置。首次落成锁定。正式迁营不允许瞬间转移：计划要求打包、装载、运输、重新布防，途中有明确风险。

后续选址应产生以下权衡，当前除障碍、资源距离和防线空间外尚未实现：

| 位置 | 优势 | 代价 |
|---|---|---|
| 林缘 | 木材、遮蔽 | 视线短、火灾风险 |
| 工业边缘 | 废金属、燃料 | 噪声、污染、较密集感染者 |
| 水源附近 | 稳定供水、农业 | 水净化、地势和潮湿影响 |
| 城镇边缘 | 医药、食物与交易线索 | 多入口、建筑遮蔽、尸群密集 |
| 开阔高地 | 射界与观察 | 水源和材料运输距离长 |

不设一个全面最优的出生点。地图应提示已观察到的信息，未侦察的风险保持未知。重要资源点手工设计，普通区域程序拼装；程序生成不负责保证每一处随机地形都值得探索。

## 布防决策

1. **路径**：围墙延长路线，营地门留出运输和逃生通道；尖刺在入口消耗尸群。
2. **射界**：炮台需要视线，墙体会挡住射击；交叉火力有价值。
3. **后勤**：发电机消耗燃料，炮台与玩家争用弹药包；电力并非永久免费伤害。
4. **冗余**：正式版分区仓储、备用电源和第二道防线，避免单点失效。
5. **维修**：攻击留下材料成本；拆除返还 50% 并向下取整，防止反复建拆套利。

原型门可手动开关，敌人会攻击阻挡物；局部避障暂不支持复杂迷宫。后续用代价寻路比较绕行、砸墙与追逐噪声，避免永远被单格堵死的无成本防线。

## 难度与公平

采用可解释的压力来源：活动噪声、发电机运行、区域危险、显眼设施和远征行为。不得在玩家周围无征兆生成惩罚尸群；尸潮从营地外围接近，并给出方向与提前预警。原型目前实现基础全局威胁条和外围生成，方向预警待补充。

尸潮规模会随波次上升，但应有上限；原型上限 24 个攻营单位。正式难度应更多通过方向、组合、补给和地形变化，而不是无限增加血量与数量。

死亡丢失背包和随身弹药，保留基地。核心被突破损失部分库存，保留恢复能力。原型损失 30%。不允许一次失误把数十小时进度彻底删除；极限永久死亡可以以后作为独立选项。

离线不被拆家，暂停可用；当前原型整备和背包暂停。后续如增加硬核模式实时背包，必须先验证移动端操作不会成为主要死因。

## 经营与成长

规划营地供水、食物、医疗、工艺、电力和防御六条生产链，互相制约。原型仅实现仓库、功能建筑依赖、燃料、弹药和维修；尚无完整生产链。

角色成长优先解锁配方、装载方式、医疗手段与侦察能力，控制直接伤害加成。幸存者计划带来职业专长、伤病、疲劳和关系，使救援任务影响营地。

长线需要可再生的低阶资源、有限高价值遗迹和远距离产业据点。原型容器不刷新，无法作为完整长期经济；新增可再生采集应优先于无限扩张内容。

## 实施顺序与通过标准

| 阶段 | 内容 | 通过标准 |
|---|---|---|
| 0.1 当前原型 | 搜刮、撤离、选址、建造、攻营、存档、APK | 完整循环可试玩，损失和材料结算无重复领取 |
| 0.2 战术基础 | 完整寻路、方向预警、建筑升级、采集与制作、区域存档 | 不存在简单无成本卡怪，长期经济可持续 |
| 0.3 基地策略 | 水源、污染、电网、分区仓库、运输、迁营 | 至少三类营址有不同合理建设方案 |
| 0.4 远征深度 | 室内、人工地标、武器与护甲、医疗细化、天气昼夜 | 同一资源目标有不同风险与路线选择 |
| 0.5 长期经营 | 幸存者、派系、商队、区域事件与长期目标 | 基地需求能持续产生多样外出目标 |

每阶段先满足通过标准，再扩大内容数量。首版不用联机服务器、PvP、付费数值、抽卡或在线强制校验。

## 多营地与物流定案

正式结构采用主基地、资源前哨、交通中转营与独立势力聚落。自有营地间为调拨，独立势力间为贸易。参考宏观战略游戏的补给线、运输能力、区域专精与路线控制。所有地点仍在同一个持久世界中，玩家可以亲自抵达。

0.1 新增：最多六座营地，独立库存；建营包需从仓库装入背包并实际携带（木材8、废金属6、罐头2，18.4kg）。两营地间至少1600世界单位。抵达另一营地核心附近使用搜索切换当地仓库。禁止远程共享材料和跨营地继承工作台、发电机功能。

原型物流为固定小批量运输：木材4、废金属2、罐头1；运费燃料1、罐头1、护卫弹药包1。出发立即扣除，货物在途持久保存；运输按在线模拟时间推进，暂停和离线不推进。距离影响用时和风险，遇袭损失四分之一货物并向上取整。结果在派遣时确定，重启不能重新抽签。这是规则验证参数，需试玩调整。

后续：区域资源专精与产能、道路通行权、运输载具容量、可选路线与护卫、可被侦察的威胁区、可视化战略地图、独立势力的需求与价格、贸易信誉。运输网络产生需要玩家亲自解决的护送、清路和维修任务。

远方营地当前冻结战斗和生产，仅运单在在线时间结算。后续使用区域摘要模拟，不会对远方所有NPC逐个运行AI，也不允许没有预警与应对窗口的远程灭营。扩张要付出人力、防御、补给和维护成本，收益递减，不能靠无限新营地复制开局资源。
