# 美术方向与首轮素材

目标：有统一材质、构图、光色与反馈的精品独立游戏画面。当前0.1.1仅是第一轮素材与UI样板，角色、建筑、道路过渡、动画与音效仍为后续工作。

风格：俯视末日林地，灰绿、泥土、锈蚀金属，营地暖琥珀光，荒野冷灰阴影；保持手机上对敌人、物资与触控目标的辨识。

现阶段采用内置图像生成工具制作以下游戏资源，输出已复制到工程内，并由主场景实际加载。不是外部游戏截图。

- `assets/forest-ground-v2.png`：低对比地表纹理。
- `assets/spruce-v2.png`：带透明通道的云杉环境素材。
- `docs/ui-v011.png`：Godot桌面渲染的当前营地界面，非Android设备截图。

## 地表生成提示词

Use case: stylized-concept. Production game asset for an original premium indie top-down zombie survival game called Ember Camp. Create one seamless square terrain ground texture, orthographic directly overhead, with understated hand-painted environmental storytelling: muted grey olive forest soil, subtle moss, dry pine needles, tiny stones, worn muddy patches. Refined painterly material detail, restrained desaturated colors, physically convincing surface texture, no large objects, no trees, no buildings, no horizon, no paths, no light sources, no text. Even diffuse overcast illumination, low contrast, tileable on all four edges. Designed to read clearly beneath gameplay sprites at mobile screen scale. The entire image is the terrain texture.

## 树木生成提示词

Use case: stylized-concept. Production sprite asset for an original premium indie top-down post-apocalyptic forest survival game. Exactly ONE mature dark spruce tree, orthographic directly overhead with a very slight three-quarter indication so the branches have depth. Rich refined hand-painted game art, irregular organic silhouette, detailed clustered needles and weathered branches, desaturated grey olive and deep blue green, soft overcast lighting and delicate occlusion within the canopy. Full entire tree canopy centered with generous transparent padding, no cropped branches, a single object, no ground, no cast shadow outside the silhouette, no text, no border, no extra objects. Genuine transparent background. Suitable as a standalone environmental sprite for a top-down 2D mobile game.
