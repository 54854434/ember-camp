# 余烬营地 · Ember Camp

离线单机 Android 生存经营原型，Godot 4.4.1 / GDScript / Compatibility 渲染。

**核心：勘探选址 → 搜集材料 → 负重撤离 → 自由扩建 → 布防 → 应对尸潮。**

这是可运行的 0.1 技术与玩法原型，采用程序绘制的俯视美术。不是完成版塔科夫，也没有联机和商业化系统。

## 已实现

- 固定种子、跨正负坐标的程序分块世界，玩家附近保持九个活动分块。
- 开局自由探索选址：点击“扎营”在身前设置核心；首次建造、撤离入库或主动扎营锁定营址。
- 持久世界内的网格建造：围墙、可开关门、尖刺路障、储物箱、工作台、发电机、炮台、扩建信标。
- 材料扣除、科技依赖、领地限制、拆除返还、设施耐久与维修。
- 尸群听觉、游荡、追击、攻击建筑和核心；三种不同速度、生命和伤害的感染者。
- 手枪、换弹、有限弹药、近战、负重、体力、饱食、出血、药品。
- 返回核心附近连续撤离四秒，将背包物资入库；受击或近敌中断。
- 发电机燃料、炮台弹药、营地威胁与可主动触发的布防演练。
- 自动保存、退出/失焦保存、写入后替换与损坏备份恢复。离线不推进尸潮。
- 最多六座独立库存营地；携带实际建营材料建立前哨。
- 营地间物资运输，扣除货物与运费、护卫减险、在途保存、按时间结算到货。
- 中文界面、触屏移动与按住开火辅助瞄准、桌面操作。

## 安装测试

在 GitHub Actions 的 `Android APK` 运行中下载 `ember-camp-debug` 产物，解压 APK 后安装到 **Android 64 位 ARM** 手机。当前是 debug 签名；它不用于上架。

用户自行进行真机安装和体验测试，本项目不依赖 Android 模拟器。

操作：左下拖动移动；右下搜索、换弹、近战、按住开火；顶部背包、建造、药品、进食、扎营、暂停。营地门附近使用“搜索”切换开关。

桌面：WASD 移动、Shift 跑步、鼠标瞄准和射击、F 搜索/门、R 换弹、V 近战、H 治疗、B 建造、Tab 背包、E 按住撤离、Esc 暂停。

## 开发

1. 安装官方 Godot **4.4.1 standard**。
2. 运行 `python3 scripts/fetch_font.py` 获取中文字体及许可。
3. 打开 `project.godot`，运行主场景。
4. 规则验证：`godot --headless --path . --script tests/test_rules.gd`。
5. 集成验证：设置临时 XDG_DATA_HOME 后运行 `godot --headless --path . --script tests/smoke.gd`，避免覆盖个人开发存档。
6. APK：安装匹配版本导出模板、OpenJDK 17、Android SDK；设置 Godot 的 Android SDK、Java SDK 和 debug keystore 路径，再执行 `godot --headless --path . --export-debug Android build/ember-camp-debug.apk`。

## 当前限制

- 世界可持续生成，但不是数学意义的无限：当前世界修改记录保存在一个 JSON 中，长时间探索会增加存档大小。后续改成分区文件或 SQLite。
- 地表生物群落为简化布局；水源、污染、坡地、资源产业链和正式迁营尚未实现。
- 门需手动开关；敌人目前采用局部避障和攻击障碍物，没有完整全局寻路。复杂迷宫仍需后续验证。
- 发电机目前给炮台供能并增加威胁；电网、线路、分配优先级未实现。
- 储物箱目前作为可建造设施，尚未扩展独立容器容量。所有营地材料仍统一结算。
- “休息至次日”恢复游荡丧尸，不刷新已搜空的容器；当前无可再生采集系统。
- 允许建立额外前哨，但首次选址后不能直接搬走已有营地；迁营需在后续实现打包、运输和损失规则。
- 建造不暂停世界；整备、背包与暂停菜单暂停模拟。这是当前单机原型的交互选择。
- 开局库存、尸潮强度、资源分布尚待真机试玩平衡；没有宣称帧率或设备兼容性已验证。
- 当前没有音效、建筑层高、室内系统、枪械改装和幸存者 NPC。

详见 [游戏框架与实施顺序](docs/GAME_DESIGN.md)、[技术边界](docs/ARCHITECTURE.md)、[手机试玩清单](docs/PLAYTEST.md)。

## 第三方

Godot 引擎使用 MIT 许可。中文字体为 Noto Sans CJK SC，使用 SIL OFL 1.1，字体许可见 `assets/OFL.txt`。游戏逻辑原创，尚未合并其他开源游戏代码；参考项目不等于已集成的依赖。

游戏源码版权保留给仓库所有者。公开发布前可由所有者选择源码许可。

当前物流是自己营地间调拨，不含 NPC 买卖、市场价格或可视化运输实体。远方营地目前冻结战斗与生产；正式的区域抽象结算尚未实现。
