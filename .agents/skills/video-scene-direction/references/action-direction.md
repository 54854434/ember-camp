# 动作指导与编排

把用户的动作意图拆成可看见的变化。舞蹈优先交代承重脚、节拍和方向。奇幻交锋优先交代谁先发起、对方如何应对，以及空间和目标最终怎样改变。

## 动作从哪里开始，怎么结束

| 字段 | 具体要写什么 |
| --- | --- |
| 起始姿势 | 人站在哪里，面向哪一个地标，哪只脚承重，双手和道具在哪 |
| 预备与触发 | 重心先落到哪、眼神先看哪、动作由鼓点、来球、响声还是另一人引发 |
| 动作轨迹 | 哪一部分先动、往哪走、快慢和幅度，其他部位保持怎样的姿势 |
| 接触与反馈 | 此刻有没有踩地、抓住、交接或碰撞。接触点之后谁改变方向，哪个物体跟着动 |
| 出镜状态 | 最终落脚、停顿、人物朝向、道具去向，以及下一镜从哪一个动作阶段开始 |

- 舞蹈短段先设计一个完整动作句。常用结构是入拍、基础动作、节奏变化、收势。动作编排要能确定重心从哪只脚转到哪只脚，双脚留在原位的舞步也要写哪部分在带动。主动作执行后，再加臂线、头发、衣角等次级动作。
- 两人互动先画出 A、B 和物件的初始位置。明确谁发起、谁接收、物件何时离开原本的手。关键接触可以放在同一镜，也可用接触前后各自清楚的画面和声音剪接。
- 奇幻战斗先给可见的目标和障碍，再写「发起 → 回应 → 结果」。一个高潮动作让观众看清起势、效果到达和造成的变化。背景效果跟随同一因果，例如冲击先卷起近处布条，再推动远处水面。多人混战时先固定主视点和方向。
- 离开人物或切换机位前留出下一镜能接的动作阶段。补生成时截取合格末帧核对脚位、肩向、手和物件状态。把首尾帧作为构图锚点时，核对所用工作流是否真正接受这类输入。

## 看片时先查动作本身

先静音看一遍，再带音乐看一遍。按时间码确认起势、承重或接触、结果和出镜姿态。跳舞的脚滑、动作振幅不稳、舞步与鼓点不合分别归因。先把缺失的动作写成一拍能完成的变化，动作已正确时再检查机位和节拍。涉及具体舞种并且动作专业性重要时，用可靠的舞者示范或自录动作参考核对。
